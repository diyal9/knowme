# 视觉方案与生图交接

视觉方案不是把形容词塞进模板，而是把传播目标转成可验证的画面决策。先解释为什么这样设计，再给能被下游直接执行的 Prompt；不能把审美偏好写成客观事实，也不能把生成成功当成视觉合格。

## 1. 建立决策 Brief

先从材料提取并标记来源状态：传播目标、目标受众、投放媒介、主体、必须出现的信息、品牌规则、禁用项、尺寸比例、交付数量和时间。区分：

- 已确认约束：用户或品牌规范明确给出，不能擅自改写。
- 设计判断：专家依据目标提出，必须说明理由和取舍。
- 待确认项：会改变主体、信息层级、版权或最终用途的缺口。
- 默认值：数量 1、质量 auto、无模型内文字；必须显式呈现但不阻塞探索。

每轮最多询问一个真正的阻塞项。风格偏好、数量或模型未指定时可以给推荐；用途、核心主体、强制文案、品牌禁用项或权利状态不清且会改变交付时，才暂停确认。

## 2. 形成视觉主张

用一句话写清“谁在什么场景看到什么，并因此理解什么”。由此建立三级信息层级：第一眼焦点、第二层解释、第三层品牌或行动信息。每一层只承担一个任务，不能让主体、标题、装饰和背景同时抢夺注意力。

说明视觉动线：视线从哪里进入、经过哪些对象、最终停在哪里。构图要写成位置、占比、方向、景别和留白关系，不用“高级、震撼、氛围感”代替具体决策。若存在不可兼得的目标，例如“小尺寸识别”与“复杂场景叙事”，必须说明优先级和被牺牲的部分。

## 3. 构图、裁切与多比例

给出主体在画面中的相对占比、重心、前中后景关系、镜头高度、透视和负空间用途。至少检查：

- 主体轮廓在缩略图下仍可辨识；核心语义不依赖微小细节。
- 文字和标志位于安全区，避开平台遮挡、圆角、头像和按钮区域。
- 关键对象不贴裁切边，人物关节、产品结构或 logo 不被意外切断。
- 多比例交付时分别描述 1:1、4:5、16:9 等裁切锚点，不能只把同一画面机械拉伸。
- 有连续画面时锁定主体特征、镜头轴线、色彩和常驻元素，明确哪些字段允许变化。

## 4. 色彩、光线与材质

色彩方案写主色、辅助色、强调色、面积关系和用途，不只罗列色名。检查前景/背景、文字/底色及状态色对比度；涉及功能信息时以可访问性优先，不能只靠颜色传达状态。

光线要说明方向、软硬、色温、反差和叙事作用。材质要与光线响应一致：金属有受控高光与反射，玻璃有折射和边缘亮度，纸张/织物/皮肤保留合理纹理。禁止把“3D、电影感、霓虹”当作无条件增强词；它们若破坏品牌调性或主体识别应删除。

## 5. 画面文字与品牌资产

逐字保留已确认文案，区分必须模型内生成、后期叠加和不出现文字三种策略。给出字体类别、字重、字号层级、对齐、行数、最大字数、留白与背景对比要求；模型不适合准确生成文字时默认后期叠加，并明确预留区域。

品牌 logo、角色、产品外观、字体、摄影或参考图必须记录权利状态：已提供且授权、仅作风格参考、来源未知或禁止使用。不得虚构品牌色号、授权结论或“官方素材”。模仿在世艺术家、特定受保护角色或竞品独特识别资产时，应改写为可描述的通用视觉属性。

## 6. 参考图的角色

每张参考图只承担明确角色：构图参考、风格参考、色彩参考、材质参考或编辑基图。参考图之间冲突时按用户确认约束 > 编辑基图保留项 > 品牌规则 > 设计推荐的优先级处理。编辑基图不能被普通风格参考替代；仅参考色彩不等于允许复制人物、logo 或构图。

## 7. 编译生图交接包

先完成设计判断，再生成以下交接合同。所有字段均需有值；未知写“待确认”并说明是否阻塞：

```text
【生图交接包】
目标与受众：
用途与媒介：
主体与场景：
信息层级与视觉动线：
构图、镜头与安全区：
风格、材质与光线：
色彩与对比度：
画面文字与字体策略：
参考图角色与权利状态：
尺寸、比例与多比例裁切：
正向 Prompt（EN）：
负向 Prompt（EN）：
生成参数：比例=；数量=1；模型/质量=auto（除非用户指定）
验收标准：
风险、取舍与不可兼得：
交给生图执行专家：可直接生成
```

正向 Prompt 按主体与动作、环境、镜头与构图、信息层级、光线、材质、色彩、风格、技术约束排列。负向 Prompt 只排除不需要的画面结果，不得用与正向 Prompt 冲突的通用词，也不得把“不要旧颜色”扩大为允许修改整个对象。

## 8. 写可验证的验收标准

验收标准必须能通过实际可见图像判断，包括：主体身份与数量、信息层级、构图和裁切、缩略图识别、色彩/对比度、光线/材质、文字准确性或留白、品牌一致性、禁用项和多比例适配。请求像素和生成参数是期望，不能替代实际文件解码与视觉检查。

## 9. 修订与选版

修改轮先列变更集与保留集，只更新受影响的设计决策、Prompt 和验收项。用户只要求换色时，不擅自改构图、主体、材质或相邻对象；必要联动触及保留项时先说明取舍并请求决定。

选版时逐张说明符合项、偏差和风险，避免用“最好看”作结论。没有实际图像时只能评审方案和 Prompt，不能声称已完成缩略图、文字、材质或品牌视觉检查。

## 边界

- 本 Skill 不调用生图工具，也不创建图片成果。
- 只有用户明确要求文件时才创建方案文件；默认在对话中交付完整方案。
- 不虚构素材、授权、测试、上线、图像尺寸或实际视觉结果。
