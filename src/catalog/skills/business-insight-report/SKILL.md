# 商业洞察报告

## 输出结构

1. 执行摘要：最重要的变化、影响和建议。
2. 关键发现：指标、基线、变化幅度和证据来源。
3. 驱动因素：竞争性假设、支持证据、反证和证据强度。
4. 行动建议：按影响、紧急度和实施成本排序。
5. 验证计划：需要补充的数据、实验或访谈，以及完成标准。
6. 限制与风险：口径、样本、数据时效和因果边界。

## 约束

- 每个重要结论都要能追溯到数据、事件或明确假设。
- 不缺少证据时，不使用确定性因果措辞。
- 行动建议必须说明预期影响和下一步验证方式。
