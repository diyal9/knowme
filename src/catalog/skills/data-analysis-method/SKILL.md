# 数据口径与可复核分析

先明确用户要回答的问题、分析单位、范围和交付物，再选择必要的清洗、汇总、比较或建模步骤。简单问题直接算答，不强制完整报告或工具链；用户提供完整材料时不擅自浏览文件、联网或重开已确定的前提。缺口只限制依赖它的结论，可算部分仍应交付。

## 从原始行建立分析集合

记录来源、字段含义、单位、时间窗、纳入/排除条件及主键；区分事件行、独立人、任务或交易。先计原始行与各类行，再按业务键形成分析集合，保留重复与排除依据。重复事件可能是真实重复操作，不能未经核验就诊断为采集故障；多源同键记录可能是版本或冲突，不能凭文件名、行顺序任取一个。

用成员清单或可复现筛选规则核对集合的交、并、差及覆盖，避免合并放大行数、把行数当人数或把非嵌套阶段当漏斗。报告所需计数、遗漏成员及各状态关系，不要求大表逐行展示。字段缺失、合法零值、无效值、互斥候选和不适用分别标记；没有来源优先规则就并列冲突，不自动补零，也不要求未知值核验后必须非零。

## 计算前固定分母，计算后对账

为每个指标写明输入集合、分子、分母、单位、筛选规则和观察窗。均值附样本数与总量；率附分子/分母，零分母标不可计算。整体率按总分子除总分母，不随意平均组率；跨期比较检查样本、单位与观察成熟度。比例、百分点与相对变化分别命名，任何敏感性数字也要重新核对自己的分母。

复杂、重复或影响决策的运算优先用本轮已授权且可用的计算能力，保留输入、表达式和实际结果；工具只能验证运算，不能证明分母或材料事实正确。无可用工具时，简单数值可手算并给算式，无法可靠复核的计算明确待验证。写入公式文本或保存artifact不是运行计算，不为获得“回执”创建无关文档或杜撰工具。

按任务交付关键合计、样本量、结果及必要集合，不把用户需要的数值只藏在临时工具正文。用合计与分组对账、独立重算或边界代入检查结果，再统一舍入；核对摘要、表格、注释和建议中的所有数字，而不只主表。

## 把未知留在条件结论中

分别报告无冲突已知子集、候选值下的条件结果与总体未知。写明每个结果纳入哪些记录、样本量及覆盖率，条件值不升级为已确认值；子集与总体口径不同，不能直接证明总体改善，也不能反过来证明总体未改善。

涉及未知值时可给条件公式、可识别界限或敏感性分析，注明未知的合法范围；比较阈值检查小于、等于、大于以及缺失分支。总体未知不意味着一切都不可判断，但每个判断都要在所有允许的取值与前提下成立。

## 判断的对象与证据强度

先确定要判断的是样本内差异、同一目标人群换方案后的影响，还是下一步行动。这些问题需要不同证据：算术分解说明观测量怎样组成，不自动识别原因；有随机或其他可信识别设计时，结论也只覆盖其人群、窗口与已测结果。

对决定建议的主张，区分“有证据支持”“与已知事实矛盾”“当前无法识别”。不支持一种因果解释，不等于已排除它，更不等于证明相反解释。检查是否存在另一种与全部观测相容、却会改变效果方向的机制，例如方案选择、未测特征或结果缺失；若仍可能，就把该方向留为未知。反例是检验推论的假想条件，不当作新增材料，也不必为简单问题编造一套数字例子。

分群后仍可能有组内选择偏差；差异重复出现、控制几个已知因素或点估计方向一致，不等于全部混杂已排除。明确哪些条件使比较对象可比，哪些尚未核实。未识别不妨碍报告已观察的差值；不把样本小直接说成不显著，也不把未检出差异说成已证明等效或安全。没有适用设计与计算证据，不报显著性或普遍效果。

## 验证、决策与全文复核

直接回答当前决策，分别说明现有证据支持什么、尚不能决定什么，以及可逆且受约束的下一步。证据有限时仍可给有条件的选择，但说明依赖的业务护栏、代价与风险，而不是假称原因已经查明。

选择会改变决策的竞争解释，提出最小核验：补哪项信息、怎样形成可比对象、观察哪个口径，以及什么结果会支持或削弱解释。收集更多同类记录可能仍保留同一偏差，说明新增证据实际解决哪个缺口；改善证据的核查不等于一次证明因果。新增阈值和业务政策标为建议，不改已有规则，也不把随机实验当每个问题的固定前置条件。

交付前逐项核对摘要、正文和建议是否保持同一证据强度。若正文说“尚不能确定”，后文不能据此断言“不会受损”“已排除”或“必然有效”。即使用“若”开头，也检查所列条件是否真的足以推出结论；撤回过强主张时一并调整依赖它的建议，而非只加一句免责声明。

用户改数据后重建受影响集合并重算所有依赖指标，撤回失效结论。按用户格式与全文字数预算压缩重复解释，保留关键结果、条件及可追溯计算；未执行的核验、实验或数据修复保持待执行状态。本方法不增加网络、工具或写入权限，也不以计算成功替代专业结论验证。
