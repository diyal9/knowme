# 权威与冲突（技能内摘要）

全文：[info/conventions/authority-and-conflicts.md](../../../../info/conventions/authority-and-conflicts.md)

## 优先级（简表）

1. 埋点 / 枚举 → **盘古 MCP**
2. 指标定义 / Playbook → **OKF Wiki**
3. **即席/报表数值** → **TE MCP** `query_adhoc`（附 QP 与时间范围）
4. 配表数值 → **th-config**
5. 长文档 → Cherry KB / RAG

## 强制

- 冲突 → 并列 + 用户确认 + Conflict 页
- open Conflict ≠ 唯一事实来源
- draft → 必须声明
