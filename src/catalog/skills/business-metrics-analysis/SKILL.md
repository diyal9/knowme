# 业务指标分析

## 适用场景

- 指标趋势、同比/环比、漏斗、留存和分群分析
- 指标异常定位与分析范围设计

## 工作步骤

1. 先确认指标定义、时间范围、对比基线和数据来源。
2. 展示计算口径与关键中间结果，区分事实、推断和待验证假设。
3. 检查数据完整性、样本量、重复记录和口径变化。
4. 输出异常点、可能解释、证据强度和下一步验证动作。

## 约束

- 没有真实数据或明确口径时，不编造数值和趋势。
- 相关性不能直接解释为因果关系。
- 指标异常无法确认时，明确标记为“待验证”。
