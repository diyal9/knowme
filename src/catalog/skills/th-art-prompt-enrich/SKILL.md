# 生图 Prompt 编译与边界检查

Prompt 编译的职责是把已确认 Brief 无损转成生成参数，不是替用户重新设计。任何增强词都必须能追溯到已确认条件或为实现该条件所必需；不能用“更高级、更统一、更电影感”扩大修改范围。

## 1. 读取输入与约束优先级

读取完整对话、最终 Brief、最近修改意见、参考图角色和用户指定参数。约束优先级为：

1. 当前明确修改与禁止项。
2. 指定编辑基图的保留集。
3. 已确认主体、用途、品牌和强制文字。
4. 上游生图交接包中的设计决策。
5. 专家推荐和模型默认值。

低优先级内容与高优先级冲突时删除或改写低优先级内容，不能平均折中。冲突会改变用户意图时停止并请求决定。

## 2. 编译正向 Prompt

按可解析顺序组织：

- `subject`：主体身份、数量、关键特征、动作和不能改变的识别属性。
- `scene`：环境、时间、空间关系和叙事重点。
- `composition`：景别、视角、镜头、主体位置/占比、视觉层级、留白和安全区。
- `style/material`：媒介、形态语言、材质和表面处理。
- `lighting/palette`：方向、软硬、色温、反差、主辅强调色及面积关系。
- `text/brand`：模型内文字或后期留白策略、logo位置和品牌限制。
- `technical`：比例、透明背景、清晰度、边缘、裁切和输出用途。

形容词必须服务于具体画面结果。重复或互相冲突的风格词会降低稳定性，应合并为少量可观察属性。

## 3. 编译负向 Prompt

负向项覆盖低清、压缩伪影、畸形、重复主体、错误肢体、意外裁切、水印、无关文字、品牌禁用项和本任务特有风险。不得把用户要保留的特征列为负向项。

“不要旧颜色”必须限定到允许修改的对象；不能写成全画面排除该颜色，否则可能误改相邻对象。正向 Prompt 已要求某材质、颜色或结构时，负向 Prompt 不得同时排除它。

## 4. 编辑任务的变更集与保留集

编辑 Prompt 先写目标对象和变更集，再写保留集。格式应明确到“对象.属性”：

- 变更集：`杯身.颜色 = 哑光黑`。
- 保留集：`杯盖.颜色 = 原银色`、`杯体.形状 = 原版`、`构图/背景 = 原版`。

编辑基图通过 `reference_images` 传入，并标明是 base image；风格参考另列角色。没有可解析的基图引用时不生成，不把风格图当基图，也不退化为纯文生图重画。

## 5. 参数映射

将比例映射到 `aspect_ratio`，数量映射到 `n`，质量和模型按用户明确值优先。用户没有指定时使用确认阶段展示过的默认值；不得在编译时偷偷增加数量、质量或额外付费步骤。

只有模型不明确且当前合同允许时才由执行阶段调用 `list_paint_models`。Prompt 中的像素、格式和质量词是请求目标，不能作为实际输出事实。

## 6. 冲突检查

发送前逐句检查：主体数量是否一致；对象属性是否串位；构图与比例是否可同时满足；文字策略是否一致；正负 Prompt 是否冲突；技术增强是否触及保留集；reference_images 的角色是否正确；参数是否超出本次授权。

发现冲突时先修正可确定的编译错误。必须改变已确认约束才能继续时返回具体冲突，不调用工具。

## 7. 输出边界

输出一个供本轮 `generate_image` 使用的完整 Prompt、negative、参数和 reference_images 映射。不要创建 Prompt 文件，不把参数长表作为成果物，也不得声称 Prompt 已生成图片或已通过视觉验收。

画面文字默认后期叠加；确需模型生成时逐字保留文案并提示准确率风险。未确认品牌资产、人物身份和版权素材不得补造。
