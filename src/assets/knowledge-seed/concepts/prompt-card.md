# 字段

| 字段 | 说明 |
|------|------|
| `project` | 项目/主题名 |
| `version` | 语义版本，可「迭代新版本」 |
| `content` | 提示词正文 |
| `favorite` | 收藏 |
| `tags` | 标签 |
| `copyCount` | 复制次数 |

# 操作

- 右键菜单：复制、收藏、迭代版本、复制卡片、删除
- 总览面板：搜索、筛选、批量管理
