# 导出

设置 → 知识库 → **导出 OKF 包**，选择目标文件夹。  
可 zip 后分享给其他用户。

# 导入

设置 → 知识库 → **导入 OKF 包**，选择对方导出的文件夹（含 `index.md`）。

# 格式

遵循 [OKF v0.1](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md)：每个 concept 为带 `type` 的 Markdown 文件。
