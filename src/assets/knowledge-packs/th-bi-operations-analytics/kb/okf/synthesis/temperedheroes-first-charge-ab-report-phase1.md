## 3. 核心指标对比

数据窗：2026-05-27 ~ 2026-05-31 · TE projectId=101 · 过滤见 §8

| 指标 | 对照组 | 实验组 | Lift | 备注 |
|------|--------|--------|------|------|
| 新用户首充转化率（漏斗 7 日窗） | **0.52%**（611/118,398） | **0.44%**（624/142,155） | **-0.08 pp** | 注册 → `gift_pack_id∈{400104,400105,400106}` |
| 首充付费用户数（事件） | **537** | **566** | +5.4% | 与漏斗口径略有差异 |
| 首充流水 sum(`generalcost`) | **632,400** | **1,009,600** | **+59.6%** | 原始 TE 字段，单位待与盘古对齐 |
| 首充人均流水 / 新进 | **5.34** | **7.10** | **+33.0%** | 上式 / 新进用户 |
| 1 档购买率（400104） | **0.44%**（525） | **0.39%**（551） | -0.05 pp | 用户数/新进 |
| 2 档购买率（400105） | **0.05%**（65） | **0.08%**（113） | +0.03 pp | |
| 3 档购买率（400106） | **0.02%**（18） | **0.04%**（50） | +0.02 pp | |
| 提前解锁占比 | — | **无法自动统计** | — | 无解锁原因埋点 |

**解读**：

1. **转化率**：实验组漏斗转化 **低于** 对照（0.44% vs 0.52%），但实验组基数更大，绝对付费人数略多。
2. **流水**：实验组首充 `generalcost` 合计 **+59.6%**，主要来自 **2/3 档购买率提升**（购买前置解锁机制生效方向一致）。
3. **1 档**：实验组 1 档率略低，可能与用户跳过直接买高档有关，需结合游戏内解锁 UI 行为再验证。
4. **提前解锁占比**仍缺专用事件/字段。

## 6. 阶段性结论

| 维度 | 判断 |
|------|------|
| 整体倾向 | **偏正向（流水）** / **转化未显著优于对照** |
| 置信度 | **中低**（有效窗仅 5 天；样本不均衡；声明实验期无数据） |
| 建议 | **继续观察**至完整 7 天窗口 + 确认开服日；补 R6 埋点后再判机制效果 |

1. **实验期与开服日不一致**：5/20~5/26 零注册，需策划确认实际开服/实验启动日。
2. **样本 +20% 偏差**：实验组新进显著多于对照。
3. **platform 过滤**：用户属性 `temperedheroes_cn` 在本窗口返回 0，当前仅用 area_id。
4. **R4/R6** 无档位解锁专用事件。
