# 综合页（Synthesis）

本目录存放 **Query 沉淀** 与 **跨 Concept 综合** 内容，type 使用 `Synthesis`。

## 何时写入

- 用户提问产生的对比表、分析结论、口径说明
- 多 Metric / 多 Event 的对照总结
- 临时 FAQ（尚未升格为 Playbook）

## 命名

`{topic-slug}.md`，frontmatter 含 `type: Synthesis` 与 `tags`。

## 与 Playbook 区别

| | Synthesis | Playbook |
|---|-----------|----------|
| 稳定性 | 探索性、可迭代 | 团队 SOP、较稳定 |
| 位置 | `synthesis/` | `semantic/playbooks/` |
