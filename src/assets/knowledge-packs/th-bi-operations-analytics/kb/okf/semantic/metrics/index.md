# Metrics

* [DAU — 日活跃用户](/semantic/metrics/dau.md) — 当日有登录行为的去重用户数
* [D1 Retention — 次日留存率](/semantic/metrics/d1_retention.md) — 注册后第 2 天仍活跃占比
* [D7 Retention — 7日留存率](/semantic/metrics/d7_retention.md) — 注册日 T 起第 7 天（T+7）仍活跃占比
* [Pay Rate — 付费率](/semantic/metrics/pay_rate.md) — 付费用户数占活跃用户数比例
* [ARPU — 每活跃用户平均付费](/semantic/metrics/arpu.md) — 周期流水 / 同期活跃用户
