# KnowMe 视觉设计系统

版本：v1.1  
主题：**清洁的智能工作台（Clean Intelligent Workspace）**

## 设计性格

KnowMe 是长期使用的本地 AI 工作伙伴，不是营销型 AI 聊天页。视觉应当精致、安静、可信，允许高信息密度，但不显拥挤。

- 中性白灰承载阅读与工作，内容卡片统一使用纯白。
- 深炭色建立结构、导航与文字秩序。
- 矿物青绿色仅表达成长、行动、成功和可用能力。
- 不使用紫色 AI 渐变、装饰光斑、过度玻璃拟态或大面积品牌色。
- 圆角克制，阴影只表达层级，不作为装饰。

## 字体规范

界面字体：`Microsoft YaHei UI` → `Segoe UI` → system-ui。Windows 中文界面优先使用为 ClearType 调整过的系统 UI 字体。  
展示标题与正文使用同一字体族，只通过字号和标准字重建立层级，禁止页面自行替换字体。  
代码与数字：`Cascadia Code` → `JetBrains Mono` → `Consolas`。

| 层级 | Token | 字号 | 字重 | 行高 |
|---|---|---:|---:|---:|
| 页面标题 | `--font-2xl` | 22px | 600 | 1.25 |
| 区域标题 | `--font-xl` | 18px | 600 | 1.25 |
| 卡片标题 | `--font-lg` | 15px | 600 | 1.35 |
| 正文 / 控件 | `--font-md` | 14px | 400–500 | 1.5 |
| 辅助文字 | `--font-sm` | 13px | 400–500 | 1.5 |
| 元信息 | `--font-xs` | 12px | 500 | 1.4 |

### 对话阅读规范

助手回复采用独立的窄阅读轨，不与底部输入框共用最大宽度：

- `--conversation-reading-max`：880px；输入框所在工作轨可保持 920px。
- `--conversation-body-size`：15px；避免回复正文呈现为文档标题级字号。
- `--conversation-body-leading`：1.68；段落、标题和列表使用紧凑间距。
- `--conversation-turn-gap`：16px；相邻对话保持清晰分隔，但不产生大块空白。
- 执行过程状态使用紧凑单行摘要，默认高度约 32px；展开详情时才增加垂直空间。

回复正文的目标是“可连续阅读的对话”，不是“铺满页面的长文档”。新增助手内容样式应优先复用这些 token，不得单独扩大阅读宽度或字号。

字体只允许 `400 / 500 / 600 / 700` 四档字重。禁止 `450 / 550 / 620 / 650` 等由浏览器合成或插值的字重。

页面必须按文字角色选择样式：`--type-page / --type-section / --type-card / --type-body / --type-support / --type-meta`。`12px` 只用于时间、路径、状态、数量和技术元数据，不得作为说明正文、表单内容或卡片标题的默认字号。

任何可见文字不得低于 12px，不使用小数字号，也不得用 viewport 宽度或 `transform: scale()` 缩放文字。字距默认 `0`，英文全大写标签除外。全局禁止强制 `-webkit-font-smoothing`，交由 Windows ClearType 与 Chromium 选择正确的抗锯齿路径。

## 间距与布局

基础间距为 4px，常用序列：`4 / 8 / 12 / 16 / 20 / 24px`。

- 图标与文字：8px。
- 表单字段间距：12px。
- 卡片内边距：紧凑 12px，标准 16px，重点内容 20px。
- 页面区块间距：24px。
- 同一工具栏内控件高度必须一致，不因标签长度改变布局。
- 左侧一级导航采用 40px 点击高度、4px 组内间隔；跨功能组使用分隔线与至少 12px 的复合留白，避免菜单项粘连。

## 圆角与阴影

| 类型 | 圆角 |
|---|---:|
| 图标按钮、紧凑标签 | 5px |
| 输入框、普通按钮 | 7px |
| 卡片、菜单、弹窗工具面 | 10px |

胶囊圆角仅用于状态、筛选 chip 和数量徽标，不用于普通文字按钮。禁止卡片嵌套卡片。默认卡片不加阴影；输入焦点、浮层和需要脱离背景的工具面才使用轻阴影。

## 按钮规范

| 类型 | 高度 | 视觉 |
|---|---:|---|
| 图标按钮 | 28px | 透明底，hover 浅灰 |
| 紧凑按钮 | 28px | 次级命令、表格操作 |
| 标准按钮 | 32px | 默认操作 |
| 主要按钮 | 36px | 单屏唯一主要 CTA |

- Primary：青绿色实底、白字，hover 使用 `--wb-accent-hover`。
- Secondary：白底、1px 中性边框、深炭文字。
- Ghost：透明背景，无常驻边框，hover 显示浅灰底。
- Danger：只在不可逆动作使用红色，不用红色表达普通失败提示。
- 图标优先使用已有 Lucide 图标；陌生图标必须有 tooltip / `aria-label`。
- disabled 同时降低对比度并禁止点击，不只改变鼠标样式。

## 交互状态

- Hover：160ms，改变背景或边框，不做明显位移。
- Active：允许 1px 下沉或轻微缩放，持续不超过 120ms。
- Focus：2px 矿物青绿色焦点环，必须支持键盘导航。
- Panel：展开与关闭 280ms；尊重 `prefers-reduced-motion`。
- Loading：保持控件尺寸稳定，不因文字变化导致布局跳动。

## 产品语义

- 「智能伙伴」是用户的个人工作代理。
- 「能力中心」管理 Agent、Skill 和 MCP 等可装备能力。
- 「工作台」承载任务、工作流和管线运行。
- 技术名词可以出现在二级说明和详情中，不作为一级导航名称。

### 智能伙伴会话 Tab

- Tab 标题优先取首条有意义的用户事实；问候语和空标题保持「新主题」。
- 标题默认单行截断，超出可视宽度时仅在悬浮后做一次轻量横向揭示，不撑开 Tab 布局。
- 不使用角色头像作为 Tab 状态标记：对话使用气泡图标，执行中使用播放/运行图标，完成使用勾选图标。

新页面和组件必须复用 `src/renderer/app/tokens.css`，不得另建字体栈、同义颜色、字号或圆角体系。字体约束由 Renderer CSS 契约测试执行，新增例外必须先更新本设计系统并说明可读性理由。
