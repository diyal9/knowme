# KnowMe 智能推荐

## 目标

将输入框 ✨ 菜单重构为“智能推荐”：根据伙伴配置、全局记忆和可用知识，给出可复用的方法与任务入口。回复末尾不再展示方法论按钮，只在上下文明确存在下一步时给出可执行操作；模型产出结构化选择时，优先展示结构化选择。

## 推荐模型

输入框推荐由「方法论 + 目标动作」组成，例如：苏格拉底提问、第一性原理分析、MECE 拆解、假设—验证、方案对比、决策矩阵、风险检查、行动项、验收清单、知识库检索、历史方案对比和团队同步稿。回复末尾推荐只允许真实操作，例如整理行动项、生成同步稿、补充风险、生成验收清单、查找相关资料和生成可发送版本。

推荐优先级：

1. 当前对话意图和未完成事项；
2. 伙伴的 Soul、领域能力、协作偏好和主动边界；
3. 全局记忆中的稳定偏好与纠正；
4. 当前会话引用、知识库和近期相关工作。

## 运行规则

- 输入框 ✨ 使用本地方法论推荐器，并结合伙伴配置；模型结构化建议优先展示在回复末尾。
- 回复末尾仅在对话内容命中明确操作意图时展示操作建议；普通信息性回答可以不展示任何按钮。
- 存在结构化选择时隐藏操作建议，避免重复或混淆。
- 每次展示 2～4 条，第一条为最推荐方案；禁止为凑数展示无关建议。
- 推荐标题简短，副文案说明作用或推荐理由；点击后发送完整、可执行的指令。
- `fill/send/copy/open_link/open_knowledge` 继续使用现有白名单；涉及发送、发布、授权、删除和破坏性操作只能生成草稿或等待确认。
- 动态建议必须经过结构校验、长度限制、重复过滤和风险过滤。
- 推荐失败或上下文不足时保持安全的本地兜底，不影响正常回答。

## 第一版交付

- 支持按回复内容识别：澄清、分析、方案比较、研发排查、会议整理、知识检索、写作交付和风险检查。
- 固定三按钮不再与模型结构化建议并存。
- 输入框 ✨ 推荐可使用轻量卡片；回复末尾操作采用扁平文字操作，默认不显示灰色底和长说明，完整说明通过悬浮提示和无障碍标签提供。
- 推荐器保持纯函数，便于离线测试；当前接入伙伴配置中的协作偏好和领域能力，完整全局记忆与知识库摘要继续沿同一接口接入。
