# KnowMe v0.4.0 交接文档

日期：2026-08-18  
分支：`refactor/renderer-react-ts`  
定位：**React + TypeScript Renderer 重构后的工程基线发布候选**（非产品增长版本）

## 正式主路径与已退役路径

| 类别 | 路径 |
|------|------|
| 主 UI | `src/renderer/app` + `src/renderer/features/*`（React/TS） |
| 壳组合 | `AppShell`、Rail、三栏布局 |
| 主进程 | `src/main.js` → `src/main/index.ts` |
| IPC | `src/shared/api.ts` → `src/ipc/*` |
| 规则 | `src/domain/*`（纯逻辑） |
| 服务 | `src/lib/*`（TypeScript，无 DOM） |
| 已退役 | 独立笔记窗、页面级 `src/*.html` 控制器（`attention-toast.html` 除外）、气泡「应用到文件」菜单 |

## 关键架构约束

- 渲染层禁止 `ipcRenderer`；经 `window.api` / preload
- 一条产品规则一个模块导出；禁止 `globalThis` 第二实现
- 新 UI 仅 `src/renderer/features/<name>/`
- 文件预算：`src/**/*.{ts,tsx}` 告警 1200 行、硬顶 2000 行
- 功能变更须有 OpenSpec change

详见 `docs/architecture.md`、`.cursor/rules/architecture.mdc`。

## 启动、测试、构建、真机

```bash
npm start                 # 开发：Vite + Electron --dev
npm run start:dist        # 加载 dist/renderer
npm run check             # test + lint + test:renderer + typecheck
npm run renderer:build    # 发行渲染产物
npm run openspec:health   # 活跃 change 工件健康
node .cursor/scripts/harness.js gate --json --change refactor-checkpoint-closeout
node openspec/changes/refactor-checkpoint-closeout/evidence/core-path-electron-smoke.js
npm run smoke:release     # 若有 dist-release
```

本轮门禁：unit **1610** pass · renderer **268** tests · lint/tsc 全绿。

3. **会话/Tab/话题轨**（分页、Codex 式 topic rail）
4. **IPC 域注册**（`registerCoreIpc` pick 域）
5. **Electron 核心 smoke**（11 项种子会话路径）
