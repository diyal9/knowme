# 核心功能

- 工作台：货架、任务、Run、管理、Studio
- 办公助理：会话、流式、内容源文件引用
- 知识网、专家库、设置（模型 / 内容源 / 连接器）

# 数据

应用目录：`%APPDATA%\KnowMe\`（会话、设置、索引）。正文在用户绑定的本地文件夹或 GitLab 工作副本。
