# Story Retro：agent-composer-quicktips

## 结果

- Agent 空状态新增快捷提示，输入工具栏的快捷操作入口更容易发现。
- 本地附件名称增加兜底，避免空白附件行造成误解。

## 经验

- 空状态需要同时维护 HTML 初始占位和 JS 重渲染占位，否则清空对话后会回退旧文案。
- OpenSpec 门禁识别 Smoke Scope 时需要使用带勾选项的标准结构。
- 快捷入口的文字、位置和展开方向应作为一个整体验证，避免只改标签而保留原有交互认知。

## 后续

- 可在真实 Electron 窗口中补充截图型 QA 证据，进一步验证不同窗口宽度下横向菜单是否需要自适应。
