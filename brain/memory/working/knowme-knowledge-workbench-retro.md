# Retro: knowme-knowledge-workbench

## 做了什么

把 KnowMe 从「对话改正文」定锚为公司知识协作伙伴 Phase 0/1：Knowledge OS、Run/Artifact、知识管家角色。

## 学到什么

- 先定 Knowledge / Tool / Run / Connector 四对象，比继续堆 Session Tab 更能破「对话限制感」
- 写盘人在环（提案卡）比自动 apply 更适合公司知识场景
- 产品知识根与 Cursor `brain/` 必须隔离，避免开发基建与用户数据混淆
