# 工作记忆

短期会话与迭代记录，定期升格到 `wiki/` 或 `knowledge/`。

## 子目录

| 路径 | 用途 |
|------|------|
| `working/` | 当前迭代笔记、Story 回顾 |
| `sessions/` | 会话摘要 |
| `issues/` | 复发问题追踪（Skill 升格信号源） |

## 升格规则

1. 单次洞见 → 写入 `working/` 或 `sessions/`
2. 确认长期价值 → `/kb-ingest` 升格至 wiki/knowledge
3. 同类 issue ≥3 → `/evolve` 提议 Skill

## 与长期记忆

| 层 | 路径 | 寿命 |
|----|------|------|
| Memory | `brain/memory/` | 迭代级 |
| Wiki | `brain/wiki/` | 领域综合 |
| Knowledge | `brain/knowledge/` | 永久、可导出 |
