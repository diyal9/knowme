# Scope

C 端桌面便签：多窗口、美观、轻量、无打扰。产品细节见本页；团队协作见 [Evolution Loop](/processes/evolution-loop.md)。

# Core behaviors

- Multi-note independent windows
- Auto-save 500ms debounce
- Tray + global hotkey `Ctrl+Alt+N`
- Persist to `%APPDATA%\sticky-notes\`
