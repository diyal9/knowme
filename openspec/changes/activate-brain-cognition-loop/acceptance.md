# Acceptance

## 结论

通过本次功能验收。Brain 已从静态知识图谱升级为受控认知闭环：对话观察先进入“待我确认”，确认后才影响 Brain 或伙伴协作方式，所有变化可解释并可撤销。

## 制作人体验验收

- 用户明确表达事实、目标、项目、决策或知识偏好后，系统生成一条待确认理解，不直接写入长期 Brain。
- 回复风格、主动程度等协作偏好进入 Partner Profile，不污染 Brain 图谱；知识偏好仍沉淀到 Brain。
- “我通常 / 我一般 / 我经常”等较弱观察先进入 Memory，达到重复阈值后才生成统一提案。
- 敏感内容、一次性会话、问句、未授权 Agent 和失败或取消的回答不会触发长期学习。
- 提案详情说明“发现了什么、为什么判断、确认后影响什么”，并展示来源、置信度和出现次数。
- 用户可在确认前修改记忆内容；确认写入的是修改后的内容，而不是原始候选。
- 拒绝后相同事实不会反复骚扰；稍后处理保留提案并暂缓展示。
- 确认后立即刷新 Brain 图谱和统计，并在最近成长中提供撤销；撤销后对应图谱节点或伙伴设置恢复。
- 页面保持 KnowMe 浅色、紧凑的编辑式视觉，1280×800 下待确认列表与解释区同时可见。
