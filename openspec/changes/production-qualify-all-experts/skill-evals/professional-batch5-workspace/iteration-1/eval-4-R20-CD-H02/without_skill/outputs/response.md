## 「夜游纸上城」票券概念方案

### 一、两个创意组织方式

**方案A：「图纸分栏」**
把整张票模拟为一张建筑图纸的横剖面。左侧60mm存根是"结构柱"——竖向粗黑线框内仅放场次编号、票号占位和一行极小的活动缩写；右侧120mm观众联是"展开立面"——金色折线从撕线处向右延伸，勾勒出一座纸建筑的轮廓，时间、地点、活动名、每票一人等信息沿折线的"楼层线"逐行排布，像图纸上的标注。视觉记忆点在于：撕开之后，观众手里拿到的不是半截票，而是一栋"被拆下来的小楼"。

**方案B：「印章对半」**
以中国传统骑缝章为原型。一个完整的金色几何图形（原创八角网格，象征印刷厂的老式字盘）横跨两联，撕开后各留一半，形成"对不上就不算数"的仪式感。存根侧保留图形的左半和票号；观众联保留右半、完整文字信息和一句主文案。信息密度集中在观众联，存根极简。

### 二、推荐方案及取舍

**推荐方案A「图纸分栏」。**

| 维度 | 方案A | 方案B |
|------|-------|-------|
| 两联独立可读 | ✅ 天然分离，各管各的信息层 | ⚠️ 图形跨撕线，观众可能试图"拼回去"才能理解 |
| 记忆点强度 | 中高——拿到一栋"纸楼"，与拼装体验同构 | 高——仪式感强，但偏静态收藏 |
| 黑金平面印刷适配 | ✅ 线条+色块即可，无需渐变或套准精度 | ⚠️ 跨线图形要求双面套印对齐，工艺风险大 |
| 与"撕开"动作的关系 | 撕开=取下建筑构件，叙事自洽 | 撕开=破坏完整性，情绪略负面 |

核心取舍：方案B的仪式感更强，但跨撕线图形在黑色平版印刷下极易错位，且会诱导观众产生"拼起来才完整"的阅读习惯——这正是M3中销售同事草稿的问题。方案A让两联在设计逻辑上就是独立单元，撕开不是破坏而是"交付"，更稳。

**【存根｜60×80mm】**

│ Ⅱ场         │  ← 场次标识，黑，12pt

```

│╱  ╲   PAPER CITY AFTER DARK  │ ← 活动名，黑，14pt + 英文副标，金，8pt
│  ╱╲                           │

│      │                        │
│      │ 凭此票入场 · 每票一人    │ ← 规则，金，9pt

│      │ NO.____                │ ← 票号占位，黑，10pt

```
主文案："凭此票入场 · 每票一人"——克制、功能优先，不出现任何暗示二次权益的字样。
禁用项：不得出现"下次""免费""通行证""抽奖"等词（与M1冲突）。

**撕开前体验：** 整票是一张完整的"建筑图纸"，左窄右宽，视觉重心自然落在右侧观众联。存根的竖线像脚手架，暗示"这部分会被拆走"。
**撕开后体验：** 工作人员拿走一根"柱子"（存根），观众手里是一栋带屋顶的小楼——与即将进行的纸建筑拼装形成动作呼应。票留在桌上或夹进书里时，它仍然是一个可辨认的建筑剪影，而非废票。

### 四、纸样检查办法

打印一张1:1黑白稿（无需真金墨），按以下步骤验证：

1. **折叠遮蔽法：** 将存根一侧向内对折完全遮住，用手机拍照。检查照片是否仍能读出活动名、日期时间、地点、每票一人、票号占位五项。若缺任何一项，观众联不合格。
2. **反向遮蔽：** 遮住观众联，只看存根。确认能独立识别场次编号和票号占位。
3. **撕离测试：** 沿撕线实际撕开（多印5份作废票），将两联随机混入另一组已撕开的票中，请一位未参与设计的人在10秒内完成"存根归存根堆、观众联按场次归堆"。若出错率＞20%，说明区分度不足，需调整字号或色彩对比。
4. **拼合诱惑检查：** 把两联重新对齐放在桌上，观察是否有明显图形引导人"想拼回去"。若有，说明跨线元素过多，需删减。

以上四步不需要联网、不需要额外授权，用普通打印机即可完成。
