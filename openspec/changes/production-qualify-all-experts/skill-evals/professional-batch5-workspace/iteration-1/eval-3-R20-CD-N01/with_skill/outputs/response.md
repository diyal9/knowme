**概念一：耳机即入口**

- **主标题：** 戴上耳机，听见旧街
- **核心视觉：** 画面中央为一副极简线条勾勒的开放式耳机轮廓（黑色），耳罩内部嵌入三段青蓝色抽象波形，分别标注“叫卖”“雨声”“电车”。背景为获准使用的空街巷照片，经高对比黑白处理，仅保留建筑轮廓与路面纹理，无行人、无舞台元素。
- **理解路径：** 远处第一眼识别“耳机”符号——非音响、非乐器；走近后看到波形被框在耳罩内，而非从扬声器扩散，暗示声音需个体接收；底部辅助文案：“城市档案馆 · 日常声音记录展”，强化档案属性。

**概念二：波形即街景**

- **主标题：** 这些波形，来自街道
- **核心视觉：** 将三段青蓝色波形横向拉伸，使其形态对应街巷照片中的实际空间结构：叫卖波形沿店铺檐口起伏，雨声波形贴合屋檐滴落轨迹，电车波形平行于轨道延伸。波形不悬浮于空白处，而是“生长”在建筑与地面之间。
- **理解路径：** 观众先注意到波形与实景的物理对齐关系，产生“这不是音频可视化，而是声音对空间的映射”的判断；标题直接点明来源，排除演出联想；辅助文案强调“无需预约 · 免费聆听”，突出低门槛日常性。

**推荐方案：概念一**

理由：通勤者停留时间短，耳机符号具有跨文化即时识别优势，能在一秒内建立“个体聆听”预期，有效区隔音乐演出的群体性、表演性场景。概念二依赖观众主动观察波形与建筑的对应关系，在快速路过时易被忽略，误读风险更高。

**另一方案代价：** 概念二若采用，需确保照片分辨率足够支撑细节辨识，且波形设计必须严格匹配实景透视，否则“映射”意图失效，反而显得杂乱；制作容错率低，不适合当前无测试稿的阶段。

**落版Brief（A3竖版）**

- **顶部1/4：** 主标题“戴上耳机，听见旧街”，黑体加粗，字号最大，居中。
- **中部1/2：** 耳机轮廓+内嵌波形组合图，占画面主体；背景街巷照片压暗至30%亮度，仅作衬底。
- **下部1/4：** 左对齐排布关键信息：  
  “10.8–10.20｜每日11:00–19:00”  
  “城市档案馆一层展廊｜免费入场·无需预约”  
  右对齐放置行动提示：“现场设耳机聆听点，欢迎驻足试听”
- **色彩规范：** 文字与图形仅用黑色与青蓝色，白纸底色；禁用渐变、阴影或装饰性字体。

**未来看稿检查项**

打印A3样张后，置于模拟通勤视线高度（约1.5米），由未参与项目的同事在3秒内扫视并回答：“这是什么类型的活动？” 若超过两人提及“音乐会”“演出”“DJ”等词，则判定误认风险未解除，需调整耳机符号比例或增加“档案”字样权重。
