# 「听见旧街」海报概念方案（两案+推荐Brief）

## 概念A：戴上耳机，才是展厅

**主标题：** 这里只出借耳机（8字）
**副文案：** 没有舞台。三段城市声音，站着听完。

**核心视觉：** 画面上半部是获准使用的空街巷照片（黑版印刷），但把青蓝色用在一条从巷子延伸出来的耳机线上——线末端挂着一副极简线条耳机，悬在街道正中。波形图缩小成三行"档案条目"排版（像目录卡片），标注：街市叫卖／雨落屋檐／电车行进。

**理解路径：** 远处先看到"耳机悬在无人的街上"这一矛盾画面——没人演出、只有物件；走近读到"只出借耳机"，明白参与方式是听；再看三条档案式波形，确认是记录而非表演。耳机是"个人聆听"的符号，直接对冲音乐节的"群体狂欢"联想。

## 概念B：声音标本

**主标题：** 收集了三种日常声响（9字）
**副文案：** 10月8日—20日，来城市档案馆听一段旧街。

**核心视觉：** 以波形为主角，但切断其"演出感"来源——三段波形各自装进三个黑色细线方框，像标本框/档案盒标签，框下配手写感的说明行（时间、地点、录音对象）。背景留大面积白纸，青蓝只用于一个方框内的波形。街巷照片压暗缩为底部窄条，作为"出处证明"。

**理解路径：** 远处看到"三个方框+大量留白"，气质接近档案展签而非演出海报；近处读"收集""日常声响"确认是记录行为。风险在于波形仍是最大视觉元素，快速路过时可能先入为主。

## 推荐与代价

**推荐A。** 它用一个具体视觉关系（耳机代替舞台、无人街道）完成"不是演出"的表达，不依赖文字解释，符合M3要求。

**B的代价：** 波形占主体，误认风险恰好落在最危险的3秒远距离阅读上；且"标本框"语言偏文人展，通勤者需要更近、更久才能解码。若设计师擅长排印、不擅长图像处理，B执行更稳——这是选B的唯一理由。

## 落版Brief（给设计师，基于A）

- **上55%：** 空街巷照片（黑版），青蓝耳机线+耳机叠在街心，耳机尺寸不小于画面宽1/5。
- **中20%：** 主标题大字"这里只出借耳机"，黑；下方一行青蓝副文案。
- **下25%信息区：** 左列三行档案条目（三类声音+小波形）；右列关键信息：10.8—10.20｜每天11:00—19:00｜城市档案馆一层展廊｜免费入场·无需预约。
- **行动提示（可直接上稿）：** "顺楼梯进来，取一副耳机即可开始听。"
- **禁用：** 艺人姓名/肖像、机构Logo、二维码、舞台灯光类效果字。

## 未来看稿检查（待执行）

**3米/0.5米两步测试：** 打印稿挂出，请5名未看过文案的路人先在3米外看3秒，问"这是什么活动？"——若≥2人答"演出/音乐会"即判失败；再允许走近0.5米自由阅读10秒，复问一次。两轮都通过才定稿。
