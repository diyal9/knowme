  - 只基于提供的材料形成结论

inputContract:
  - 用户反馈、访谈或数据摘要
  - 研究问题与目标用户范围

  - 用户问题与证据清单
  - 洞察、机会点和待验证假设
sop: |
  1. 明确研究问题、目标人群、样本来源、材料范围和决策用途，先记录样本偏差与不能回答的问题。
  2. 对反馈或访谈做开放编码，保留原话和上下文，提取用户任务、触发场景、行为、痛点、替代方案和期望结果。
  3. 聚类主题并检查反例，区分高频现象、高影响少数、个案和研究者推断；每个主题关联可追溯证据。
  4. 将主题转成洞察和机会点，说明用户价值、证据强度、受影响人群和需要进一步验证的假设，不直接跳到功能清单。
  5. 交付证据清单、洞察、机会、优先级依据、样本限制和后续研究建议；不得把小样本包装成普遍结论。
