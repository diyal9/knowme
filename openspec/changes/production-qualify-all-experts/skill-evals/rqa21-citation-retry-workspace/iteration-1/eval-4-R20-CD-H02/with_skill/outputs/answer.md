## 创意命题与两方案比较

**核心命题**：让撕票动作本身成为“建筑落成”的隐喻，同时保证两联各自独立承载完整信息。

**方案A｜“蓝图对折”**
整张票正面印一幅连续的建筑立面线稿（黑金线条），横跨存根与观众联。撕开时，线稿沿撕线断开——存根带走“地基/入口段”，观众联保留“主体/屋顶段”。时间地点等文字在两联上各印一份（字号缩小但完整可读）。记忆点在于：撕开的瞬间像把一张完整图纸拆成两半，各自仍是一栋“可辨认的小建筑”。

**方案B｜“楼层剖面”**
利用180×80横版比例，将票面纵向分为三层“楼层”网格。存根占左侧60mm，内部用金色折线画出“底层门厅”图标+场次+票号；观众联右侧120mm用同一套网格语言画出“二层工坊”图标+活动名、时间地点、每票一人、票号。两联视觉风格统一（共享网格母题），但内容完全独立，无需拼合即可阅读。记忆点在于：拿到票先看到一栋“纸楼剖面”，撕开后各持一层，暗示“你进入的是这栋楼的某一层”。

**推荐方案B，取舍理由**：
- 方案A的连续线稿虽美观，但撕开后两联各自只剩半截图形，若文字也做跨联处理则违反M2“独立可读”硬约束；即使文字双份，半截线稿在60mm存根上辨识度低，工作人员核对效率下降。
- 方案B以共享网格母题保持整体感，同时天然满足“两联各自可用”；60mm存根只需容纳一个图标+两行关键文字，空间充裕；观众联120mm有足够层级放全量信息。
- 销售草稿中“拼起来才读得到”和“下次免费通行证”均不可采用：前者违反M2，后者虚构了不存在的权益（M1明确无第二次入场）。方案B从结构上杜绝跨联依赖。

## 推荐方案版面与文案安排

| 区域 | 存根（左60mm） | 观众联（右120mm） |
|---|---|---|
| 顶部标识 | 金色小字“夜游纸上城” | 黑色主标题“夜游纸上城”+金色副标“纸建筑拼装体验” |
| 中部图形 | 金色折线画“门厅拱形”简笔图标 | 金色网格+折线画“二层工坊窗格”简笔图标 |
| 信息区 | 第1行：11.6 19:10<br>第2行：票号 [____] | 第1行：11月6日 19:10 · 旧印刷厂二层工坊<br>第2行：每票一人 · 凭此券入场<br>第3行：票号 [____] |
| 底部备注 | 无 | 灰色小字“本券为单次体验凭证，不含额外权益” |

**撕开前体验**：观众手持完整票，从左到右读到“门厅→工坊”的空间叙事，建立“即将进入一栋纸建筑”的预期。
**撕开后体验**：工作人员收走存根，仅凭60mm即可确认场次与票号完成核销；观众保留120mm票，所有后续辨认所需信息（活动名、时间地点、人数限制、票号）均在单联内闭环，遗失物核对无需回溯另一联。

## 纸样检查办法

打印一张180×80mm黑白灰度纸样（模拟最终尺寸），沿预设撕线裁开，执行以下三步：
1. **遮挡测试**：遮住任意一联，检查另一联是否能在正常阅读距离（约30cm）下读出全部必需字段（存根：场次+票号；观众联：活动名+时间+地点+每票一人+票号）。任一字段缺失即判定不合格。
2. **缩略识别**：将两联分别拍照缩小至手机屏幕宽度约40%，确认图标轮廓与文字块仍可区分主次层级。
3. **误读排查**：请一位未参与设计的人只看观众联，口头复述“这张票能做什么、不能做什么”，验证不会出现“可再次入场”或“含赠品”等错误理解。

以上为文字概念阶段交付，不涉及实际印刷工艺参数或生图指令。
