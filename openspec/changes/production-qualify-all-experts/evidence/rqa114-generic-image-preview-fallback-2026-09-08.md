# RQA114 — 通用图片预览回退契约

时间：2026-09-08

## 目的

修复图片成果只有一个预览地址时的通用可靠性缺口：远程 CDN 地址失效后，即使本地已经成功解码并保存图片，界面也会显示破图或空白。

## 修改

- `src/domain/artifact-preview.ts` 增加有序 `sources` 候选列表；保留首选 provider URL，同时允许回退到本地成果路径。
- `useArtifactPreviewSource` 统一处理远程、data URL 和本地文件候选；远程 `<img>` 加载失败后自动尝试下一候选。
- `ArtifactPreview`、专家图片预览、普通 Agent 成果卡统一消费同一回退契约。
- 未改变图片状态、验收操作或真实工具证据门禁。

## 验证

- 图片契约、共享预览、缩略图布局：`18/18` 通过。
- 完整 `npm run check`：后端 `3513` 项，`3462` 通过、`51` 跳过、`0` 失败；Renderer `86` 个文件、`622` 项通过；lint、CSS cascade、脚本范围和 typecheck 均通过。
- 新回归实际模拟了 CDN 图片加载失败，并确认界面切换到本地 `data:image`，没有产生空白成功卡片。

## 结论

该问题已在平台级成果物预览协议层修复，不是生图专家专用分支。它改善图片交付可靠性，但不等同于真实生图 Provider、图片内容质量或独立专业评审已经通过；生产资格仍保持未完成。
