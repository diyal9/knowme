# RQA171：Provider 凭据恢复引导

日期：2026-09-09

## 修正

设置页原先把 `secure_storage_unavailable` 和 `decrypt_failed` 都提示为“请重启应用”，无法区分系统能力缺失与历史密钥失效。

现在按运行时契约分别提示：

- 系统安全存储不可用：提示使用正式安装版或启用系统凭据服务，并允许重新输入后保存；
- 历史密钥无法解密：提示重新输入 API Key 并保存。

两种状态都保留“已保存但当前无法解锁”的事实，不把配置存在误报为可执行，也不引导任何明文密钥迁移。

## 验证

- 设置页 Renderer 定向测试：`9/9`；
- `npm run typecheck:renderer`：通过；
- `npm run lint`：通过，无错误；
- 生产环境直接 Electron 探测仍记录于 RQA170，当前 `safeStorage` 不可用的事实未改变。

该修正改善阻塞态可恢复性，但不构成 Provider 真实调用或专家专业资格通过证据。
