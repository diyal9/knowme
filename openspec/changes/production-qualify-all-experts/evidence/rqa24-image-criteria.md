# RQA24 生图与参考编辑验收标准（预观察冻结）

冻结于2026-09-06；仅依据expert-rubrics.md §09和当前image-producer E/C/L，尚未读取本轮实图/运行输出。不生成图片、不调用模型/UI/QA、不修改源码或原rubric。

## 任务与范围

v1：用户已确认的一张1080×1440、3:4竖图，墨绿背景，左侧银色保温杯，右侧留白，无文字/Logo，auto质量。

v2：以上一版实图为参考，只将杯子改哑光黑，其他保留。验证真实调用与真实画面两条证据链，不能以prompt或success替代目视质量。

源码版本E/L为3.3.0、C为3.2.0，hash已记入JSON。这不是实际QA安装证明，不据此推断运行根因，也不修包。仅新增标准数据/文档，无既有函数符号编辑，impact不适用。

## 冻结检查项

- **R24-S1 / v1 / authorization_sop**：已有完整Brief且用户明确确认后才生成；不重复追问已给定主体、比例、数量等，不把交接包就绪当额外付费授权。
  证据：实际确认/交接消息时间与生成调用顺序；缺完整历史则not_evaluable。

- **R24-S2 / both / execution_provenance**：v1与v2分别有真实成功生图/编辑调用和可读取的image artifact，各交付一张；prompt、success文本或文件名不能替代图片。
  证据：task/session/run、toolCallId、真实工具名/参数/结果及artifact引用映射，原始图片可读性。平台包装不得重复算生成次数。

- **R24-S3 / both / authorization_sop**：采用当前实际授权的盘古生成能力；模型未知时有模型发现依据；不因可选Photoshop不可用阻塞，不擅自额外付费重生成或交付参数文档文件。
  证据：完整工具日志与确认范围；模型已明确可不调用list_paint_models。不要求使用Photoshop或不可用的工具。

- **R24-V1 / v1 / visual_v1**：完整实图为单个银色金属保温杯，主体可辨、形体连贯，杯体没有影响交付的明显融合/断裂/重复部件。
  证据：原始完整图片与必要局部观察；不预设杯盖形状、手柄、特定品牌或唯一审美方案。

- **R24-V2 / v1 / visual_v1**：墨绿背景，杯子位于画面左侧；右侧有连续可用留白，不被额外主体或繁杂装饰占据。
  证据：完整实图，观察主体位置与负空间功能；不事后设固定留白面积百分比，容许自然渐变/柔和阴影。

- **R24-V3 / both / visual_shared**：两版实际图均为竖幅3:4；原Brief要求1080×1440时，核对实际像素尺寸为1080×1440，不能以工具请求尺寸当返回尺寸。
  证据：原始文件解码尺寸；比例满足但分辨率不符时记录具体format_noncompliance，不能说画面内容失败。缩略图尺寸不能替代原图尺寸。

- **R24-V4 / both / visual_shared**：两版完整画面无文字、Logo或可见水印/伪文字，不把后续文字区画上占位文案。
  证据：完整图片及足够清晰局部；UI按钮/标题不属于图片文字。分辨率不足以观察时明确not_evaluable，不从prompt宣称无字。

- **R24-R1 / v2 / reference_edit_provenance**：v2实际调用的reference_images绑定已交付v1图片；不能空参考纯文生图重画冒充编辑，也不能引用无关图或仅在自然语言里提及上一版。
  证据：实际toolargs的reference_images及其URL/路径/ID到v1 artifact/原图的可核查映射。可接受主机合法解析/转换后的引用，但须有映射证据；不强改工具接口。

- **R24-R2 / v2 / reference_edit_sop**：实际编辑prompt首句明确只将杯子改哑光黑，并明确保留背景、构图等其他内容、排除旧银色杯身；不能仅在最终答复写编辑要求。
  证据：真实调用参数内完整prompt；工具支持参考编辑的实际证据与返回结果，不要求暴露模型内部过程。

- **R24-R3 / v2 / visual_v2**：实际v2杯体由银色变为可辨认的哑光黑；不能仍为银色、仅整体压暗或只是高镜面亮黑而未实现哑光材质。
  证据：v1/v2分别全图和并排杯身细节；容许黑色材质的柔和高光和必要边缘反射，不要求纯RGB黑或完全无反光。

- **R24-R4 / v2 / visual_v2**：定向编辑后仍保持同一杯型/主体数量、左侧位置、主要轮廓与视角、墨绿背景、右侧留白、3:4与无字无Logo；不擅自添加道具、改变设计或大幅重构。
  证据：v1/v2可比尺度完整对照。容许变材质所需的局部光影、反射和轻微生成纹理差异；不要求像素一致、完全相同文件hash或固定相似度分数。

- **R24-P1 / both / preview_ui**：每版缩略图能作为独立图片识别，且预览绑定正确版本，不出现错误旧图/串图、破图或相邻消息图片混合。
  证据：主线提供的带版本上下文UI证据及对应图片引用；孤立裁图可辅助看画面，但不能独自证明版本绑定。UI缺证不否定已读取原图的视觉质量。

- **R24-P2 / both / preview_ui**：打开完整预览时以contain或等效完整适配呈现整幅3:4图片，四边与留白可见、不拉伸；不能只凭裁切缩略图判断完整构图。
  证据：全预览截图/记录与原图比对；黑边或留白适配允许。缩略图可裁切，但必须有可访问完整预览，不能将thumbnail crop误判为原图裁切。

- **R24-T1 / both / truthful_delivery**：对话简短交付（约两三句话），图片才是成果；对已看见的画面做有根据说明，未获得视觉输入则明确未检查，不能把prompt/成功回执说成视觉要求已验证。
  证据：完整assistant答复、当次模型实际可见视觉输入/工具结果。独立评审者看过图片不证明原Agent看过；视觉缺证时不要求编造自查或触发额外生成。

## 如何判定，避免误归因

每项按版本记录pass / fail / not_evaluable，分别对应passed=true / false / null。N/A不计分母，但未覆盖项必须明确，不能拿剩余项通过率总放行。视觉、格式、参考来源、权限/SOP、预览和交付诚实度分别统计。

- 有图且看见银色未变黑，是视觉失败；没有可读图，是视觉不可评。工具无图仍宣称完成，是执行/诚实交付失败，不虚构视觉失败。
- 完整参数显示reference_images为空/指向无关图，是参考链失败；只缺参数导出，是缺证，不猜纯文生图。自然语言“用了上一版”不能证实真实工具引用。
- 合法host解析后的URL/路径可接受，但须映射到v1真实artifact；不改接口、不要求仅某种引用表示。
- 比例正确但非1080×1440，是具体输出格式不符；不能以请求参数代替实测尺寸，也不能把缩略图缩放尺寸当原图尺寸。
- 缩略图裁切和完整原图裁切是不同问题。独立缩略图应绑定正确版本；contain或等效完整预览应可见四边与右侧留白，允许适配黑边，不允许拉伸。UI缺证不否定已见原图。
- 材质变化允许必要光影/反射变化、轻微生成纹理变化；不要求像素一致、固定差异阈值或毫无高光的RGB纯黑。明显换杯型/换构图、背景漂移或无关新增仍须判实质编辑不符。
- 对“已检查哑光黑/构图保留”的Agent声称，须核对该回合视觉输入；评审者后来见图不等于Agent当时见图。缺视觉时诚实说明未检查可符合SOP，不能默认要求额外付费重试。

## 后续所需证据

- v1/v2实际任务/session/run、确认/反馈消息、完整assistant和工具调用结果；实际安装snapshot/版本可独立记录。
- 两版原始可解码图片、artifact ID与引用、像素尺寸/内容hash；不要只给拼贴或文字描述。
- v2实际reference_images和完整prompt，host解析映射（如有）、结果artifact及previousVersionId或等效版本关联。
- 每版独立缩略图与contain全预览证据，带可辨版本上下文；禁止把UI组件文字算图中文字。
- 当次Agent实际收到的视觉输入证据（若缺失如实标记），不能用评审者后来见图替代。

只审实际提供的一次生成及一次参考编辑。空图、失效链接、模型不支持编辑等异常处理属于既有SOP边界，若本轮未发生则不宣称通过异常回归。文本简洁性不抵消画面硬伤；工具及任务verified/review也不认证专业质量。此测试不是方法A/B或专家生产资格认证。

机器可读标准与完整来源hash见同目录rqa24-image-criteria.json。后续评分不得看完图片再加留白比例、唯一杯型或像素相似度等新门槛。
