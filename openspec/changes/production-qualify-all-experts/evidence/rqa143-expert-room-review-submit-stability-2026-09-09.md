# RQA143：专家房验收修改提交稳定性

日期：2026-09-09

## 问题

专家房“修改成果”回归用例原先只等待图片/成果预览出现，就立即向唯一输入框提交修改意见。完整 Renderer 套件中曾出现一次提交未触发的时序失败：验收动作尚未完成挂载时，测试抢先提交了表单。

## 修复

回归用例现在显式等待“接受成果”验收入口出现，再验证唯一输入框可以直接提交修改意见。该修复收紧了测试对可交互状态的判断，没有增加额外按钮，也没有改变用户需要在主输入框提交修改意见的产品流程。

- 完整 Renderer：86 个文件、630/630 通过；
- lint：通过；
- typecheck：通过。
