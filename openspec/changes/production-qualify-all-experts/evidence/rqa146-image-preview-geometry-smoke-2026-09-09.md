# RQA146：通用图片预览组件几何冒烟

日期：2026-09-09

## 验证内容

执行 `scripts/image-preview-smoke.py`，直接加载当前 Renderer 的通用图片预览页面，在桌面、窄窗口和移动尺寸下分别打开 3 张图片，验证：

- 缩略图按顺序独立展示；
- 点击缩略图后打开统一预览对话框；
- 原图可解码，不能把 URL 或说明文字当成图片；
- 图片使用 `contain` 完整适配预览区域；
- 对话框和图片均不溢出视口；
- 预览组件通过 Portal 挂载到 `document.body`，不被专家房滚动容器裁切。

## 结果

- 视口：`1280×820`、`835×680`、`390×650`
- 图片：每个视口 3 张
- 通过：`9/9`
- 失败：`0`
- 页面异常状态节点：`0`

该结果证明通用图片预览的布局和查看交互在当前 Renderer 中稳定；它不替代真实 Provider 的图片生成质量评审。
