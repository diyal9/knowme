# RQA160：生图夹具可见预览与完整生命周期重放

日期：2026-09-09

## 修正

资格生图夹具此前返回 1×1 PNG，只能证明存在图片字节，不能有效验证预览尺寸、裁切、版本差异和对话中的可见成果。本轮改为确定性生成 256×256 PNG 机器人图标：

- 图片可解码、尺寸来自实际文件，不依赖远程资源；
- 修改/重试轮使用不同的确定性图片版本；
- 无图片故障仍只返回文本，不生成空白或伪造成果。

## 资格边界

该夹具证明的是通用运行时、图片 artifact、预览和生命周期协议，不证明真实 Pango 输出的构图、主体、风格或品牌一致性。真实 Provider 仍需在线，图片内容仍需独立专业视觉评审；`professionallyQualified=0 / productionReady=false` 保持不变。
