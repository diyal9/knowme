# RQA79：保留专家合同审计与继续条件

日期：2026-09-08

## 结论

当前暂停目标可以继续，不需要扩大专家范围，也不需要重新创建目标。生产级验收必须分成四道独立门禁：

1. **静态合同门禁**：专家声明的 Skill、Connector 和版本可解析。
2. **运行时门禁**：KnowMe 能完成预检、对话、确认、工具调用、成果物、失败、重试、修改和重开闭环。
3. **真实能力门禁**：当前 Provider、连接器和外部服务真的返回可核验结果。
4. **专业质量门禁**：独立评审确认结果满足专家 SOP、事实边界和交付质量。

前两道门禁已有工程证据；第三道门禁在隔离 Electron 验证中被环境阻塞，第四道尚未完成。因此当前状态是“可以继续推进”，不是“专家已生产级通过”。

## 当前证据与下一步

- `eval:experts:matrix`：6/6 `ready_for_live_execution`，表示冻结用例齐全，不代表专业资格通过。
- 隔离 Electron 真实资格验证：27/27 因 Provider 或能力环境阻塞进入 `needs_input`，0 次误报运行失败；未产生可用于专业认证的真实工具/成果物证据。
- `attention.issues` 已能把多个阻塞原因一次性保存、恢复并展示，后续真实环境可直接定位缺少的 Provider、Connector 或授权，不再靠重复试错。

继续顺序固定为：

1. 在用户明确授权且真实 Provider/连接器可用的环境中，逐专家执行冻结套件。
2. 保存输入、模型/工具调用回执、成果物字节或来源、生命周期状态和失败恢复记录。
3. 由独立评审逐用例判断专业正确性；任一硬性专业错误都不能被平台测试绿灯覆盖。
4. 只对通过真实能力与专业质量门禁的专家标记生产级；未通过者保留为候选并继续修正，不新增无证据的专家。
