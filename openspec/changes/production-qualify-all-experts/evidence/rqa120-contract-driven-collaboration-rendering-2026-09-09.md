# RQA120：基于活动契约的协作展示

## 变更

- 专家协作叙事优先使用 `source: user` 判断用户回合；仅对没有来源字段的旧事件使用事件类型兼容回退。
- 专家任务时间线优先使用 `source/kind` 判断用户、系统和专家角色及分类；新增 Agent/Skill 的用户事件不再需要把事件类型加入页面白名单。
- 保留旧任务和旧事件的展示兼容，主对话只显示用户正文，不把时间线分类标签重复塞入对话气泡。

## 验证

- 协作叙事：`9/9` 通过，包含未知事件类型但明确 `source=user` 的用户回合。
- 专家房回归：`68/68` 通过，覆盖通用用户事件进入主对话并保持用户角色。
- Renderer 全量：`86` 文件、`625/625` 通过。
- lint：通过；类型检查：通过。

## 边界

这项变更提升通用 Agent 编排层的展示扩展性，不改变真实 Provider、工具授权和专业质量认证状态。当前生产审计仍有 7 条条件路线等待真实执行回执。
