# RQA26：参考编辑运行时修复与生图专家整包对照

## 结论与范围

本轮修复了两个通用运行时问题，并将自有生图专家包统一到 3.4.0。修复后两个冻结场景的旧/新包四次真实参考编辑均返回一张可读图片；独立专业评分旧包两题各 8/9，候选两题各 9/9。差异是简洁交付要求，不是图片视觉质量显著改善的证据；两边均未发现冻结标准定义的确定性专业硬伤。**不认证生图专家，更不代表 24 专家目标完成。**

真实测试只使用自有隔离 QA profile 与 CDP 9223。没有修改日常 KnowMe 数据、覆盖外部 linked Skill、接受成果、提交 git，或为凑结果额外付费生成。使用同一真实可参考编辑模型 `gpt-image-2`、quality=auto、n=1、896×1200 请求；四次均从同一原始银杯 JPEG 开始。参考图 SHA256 为 `6c8124d9d8735d9b3133e402172fe7096fd3e52a9bbe474c90394aa86582ff33`。

## 修复内容

1. **本轮附件可见但无法作为编辑参考。** 原运行已把真实图片交给语言模型，却没有给生成工具可解析的引用，`generate_image` 在参考解析阶段被拒绝。本轮增加按图片原字节 SHA256 标识的附件引用；模型消息构造与实际工具面复用同一附件集。只允许本轮明确提供的引用，不以文件名、任意路径、其他会话或被截去的第 4 张图扩大权限。生产组装回归覆盖草稿与 payload 不同、草稿空集优先、跨会话及同名图片等情况，没有专家 ID 特判。
2. **尚未调用服务却误报副作用未知。** 引用解析/空提示词等宿主前置失败使用进程内可信标记；工具契约和通用工具面保留“尚未发出”的事实。服务自己声称 `executionStarted:false` 不被信任。已发出后的超时、断连、保存失败仍走原有未知副作用策略，不据此放开自动付费重试。
3. **自有包与方法一致性。** EXPERT、legacy manifest、canonical manifest、catalog 统一 3.4.0。SOP 明确修改项/保留项、完整最终提示词冲突检查、请求参数与真实元数据及视觉事实分离、短答复交付和付费授权边界。未增加 Skill 数量或覆盖三份外链 Skill；这些方法在旧运行已进入模型输入，因此不能把本轮进步解释为“终于安装/读到了 Skill”。引用方法文件是否另行读取仍需单独证据。

通用契约说明见 `docs/agent-image-artifacts.md`；独立源码审查见 `rqa26-attachment-review.md`、`rqa26-dispatch-review.md`、`rqa26-package-review.md`。
