## 经营判断：建议在该同一渠道扩大新版B

**结论先行**：实验满足预注册、随机等分、无提前停止、口径一致、全样本满7天观察的前提，数据完整可比。B组在两项预定目标上均优于A组，且成本约束达标——**在同渠道范围内可以做出扩大决策**。知识库检索未命中相关SOP条目（一次未授权、两次空结果），本判断完全基于用户提供的实验数据本身计算，不依赖外部资料。

---

### 一、核对分组与完整性（计划步骤1）

| 检查项 | 结果 |
|---|---|
| 随机等分 | A=10000、B=10000 去重新访客，比例1:1，无SRM异常 |
| 观察成熟度 | 全部样本满7天，D7数据成熟 |
| 口径一致性 | 埋点、归因、花费（各20000元）一致，无提前停止 |
| 数据自洽性 | D7活跃⊆注册用户，400<800、720<1200，无矛盾 |
| 错误率 | 两组均0.1%，对称，不构成干扰因素 |

### 二、指标与成本计算（计划步骤2）

| 指标 | A（旧版） | B（新版） | 变化 |
|---|---|---|---|
| 注册率 | 800/10000 = **8.0%** | 1200/10000 = **12.0%** | +4.0个百分点；相对+50% |
| 注册→D7转化率 | 400/800 = **50.0%** | 720/1200 = **60.0%** | +10.0个百分点；相对+20% |
| 每访客D7活跃率 | 400/10000 = **4.0%** | 720/10000 = **7.2%** | +3.2个百分点；相对+80% |
| 每注册成本 | 20000/800 = **25.0元** | 20000/1200 = **16.67元** | −33.3% |
| 每D7活跃成本 | 20000/400 = **50.0元** | 20000/720 = **27.78元** | −44.4%，**低于旧版，约束达标** |

关键中间量可复算：B的每访客D7优势 = 注册率提升(×1.5) × 注册后D7转化提升(×1.2) = ×1.8，即+80%，与直接计算7.2%/4.0%一致。

显著性说明（不伪造检验结果）：两比例z检验下，注册率差异 z≈9.16、每访客D7差异 z≈10.2，远超常规阈值，差异几乎不可能由抽样噪声解释。**证据强度：高**（针对"同渠道、新访客、7天窗口内注册与D7活跃"这一具体命题）。

### 三、扩大决策与监测条件（计划步骤3）

**现在可以做**：
- 在该渠道将新版B作为默认版本放量。建议先放量至50%~80%，保留小比例A对照桶1~2个投放周期，而非一刀切100%——理由是保留持续对照，可随时发现放量后的稀释或衰减效应。此动作不涉及预算调整授权，仅为版本配置建议。

**放量后观察指标与停止条件**：
| 观察项 | 判断标准 |
|---|---|
| 每访客D7活跃率 | 若较实验期B值（7.2%）回落超20%（即跌破约5.8%）且持续一周以上，暂停放量并回查 |
| 每D7活跃成本 | 超过A基线50元即触发回撤评审 |
| SRM检查 | 放量后各组实际样本比例偏离预设超±3%时，先查分流再读指标 |
| 注册→D7漏斗分段 | 确认优势仍来自注册环节，防止放量后新增流量质量结构漂移掩盖问题 |

### 四、证据边界（明确写清，但不因此阻塞当前决策）

1. **不外推**：结论仅适用于该投放渠道的新访客。其他渠道的流量质量、用户构成不同，需各自跑实验或在放量后单独分渠道监控，不能引用本数据背书。
2. **收入与LTV未知**：本实验只证明"注册和D7更便宜、更多"，未证明"更赚钱"。D7→付费、ARPU、长期留存均未测量。**需要验证后再做**的动作是加预算扩量——建议由投放/商业化负责人补测B组用户的D30留存与首充率，若B组D30留存或付费率显著低于A组（例如低15%以上），应重估扩大范围。
3. **机制未证**：B优于A是事实，但"为什么优"（哪个玩法/流程改动驱动）无法从聚合数据区分。建议拆解注册漏斗的分步流失对比，定位驱动改动，避免后续迭代复制不了成功要素。
4. 数据为用户提供的虚构实验数据，以上计算全部基于该输入，未查询也未采用任何外部资料。

**一句话交付**：同渠道扩大新版B，证据充分、成本约束达标；保留对照桶放量，盯住每D7活跃成本≤50元和D7率≥5.8%两条红线；加预算前补收付费/LTV数据。
