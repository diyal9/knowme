# RQA189：保留专家包与依赖闭环复核

日期：2026-09-10

## 验证范围

对当前保留的 6 位专家执行静态合同复核：

- `product-manager`
- `office-partner`
- `research-analyst`
- `software-engineer`
- `data-analyst`
- `image-producer`

复核覆盖 manifest/SOP、必需 Skill、条件执行路线、工具权限、退休专家治理、统一运行时分支和独立专业评审契约。

## 结果

- 定向回归：`36/36` 通过。
- `npm run eval:experts:matrix`：6/6 `ready_for_live_execution`。
- 退休专家不会重新出现在新任务入口；Skill-only 能力通过通用能力面进入。
- 每个保留专家都有可执行的交付、验收、异常和修订结构；平台运行时不依赖具体专家 ID 分支。
- 独立评审必须覆盖所有案例，并且证据锚点必须命中当前助手输出或成果物；不能用用户提示词、空字段或同一执行模型冒充独立评审。

## 边界

静态包闭环不等于生产资格。真实资格仍要求：

1. 当前真实 AI Provider 成功返回；
2. Feishu/Pango/网络等声明路线取得当前工具回执；
3. 正常、边界、重试、修改、重开案例完整运行；
4. 每个案例完成独立专业语义评审。

当前沙箱无法继承原 KnowMe 桌面安全存储，历史授权证据已单独记录，不提升当前生产资格。
