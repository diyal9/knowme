# RQA172：最终交付摘要回归修复

日期：2026-09-09

## 发现

完整 Renderer 门禁发现专家能力侧栏的“交付”摘要同时读取计划交付和任务历史交付，导致待验收、证据被阻塞、缺少资源引用的内部记录也可能出现在最终区域。

## 修正

- 任务已经产生交付记录时，摘要只采用“已接受、非阻塞、存在 artifactRef/artifactRefs”的交付；
- 没有任务交付记录时，才展示初始计划中的预期交付；
- 侧栏成果物列表继续使用同一有效资源与接受状态过滤。

这保证用户看到的“交付”与可打开的真实成果一致，不把候选、失败或内部治理状态当成最终结果。

## 验证

- 专家访问/能力、专家房间、图片预览定向测试：`87/87`；
- 完整 Renderer：`86` 个测试文件、`632/632`；
- `npm run check:quick`：通过；
- `npm run typecheck:renderer`：通过；
- `git diff --check`：通过（仅保留既有 CRLF 提示）。

该修正属于通用成果物展示层，不构成真实 Provider 调用、外部连接器回执或独立专业资格通过证据。
