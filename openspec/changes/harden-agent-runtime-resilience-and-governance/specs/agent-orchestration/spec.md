## ADDED Requirements

### Requirement: 编排层必须传播后端健康与降级语义

编排层 MUST 在任务编排事件中传播远程健康状态、降级触发原因与恢复建议，使父 Run 能够感知并决策后续动作。

#### Scenario: 子 Run 触发降级

- **WHEN** 子 Run 从远程执行降级到本地执行
- **THEN** 编排事件中包含降级原因和后续建议

### Requirement: 编排层必须区分可重试与不可重试故障

编排层 SHALL 对故障分类输出重试语义，避免统一重试导致资源放大。

#### Scenario: 不可重试故障

- **WHEN** 故障类型为签名拒绝或策略阻断
- **THEN** 编排结果标记为不可重试并给出替代路径
