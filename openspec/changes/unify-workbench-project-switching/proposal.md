# Why

KnowMe 已经有稳定的 Project Context，但工作台内仍缺少全局可见的项目切换入口。用户在专家协作、工作流和管线服务之间切换时，无法持续确认当前工作边界，而左侧“文件”的命名也弱化了项目心智。

# What Changes

- 在工作台顶部增加共享项目上下文切换器，对专家协作、工作流和管线服务同时生效。
- 将左侧“文件”入口和相关文案升级为“项目空间”，仍保留真实文件树。
- 从项目切换器直接打开或新建本地项目、进入 Git 仓库接入以及管理项目元数据。
- 工作流和管线历史默认只显示当前项目，同时保留“全部项目”的历史查看范围。
- 创建管线任务时要求选中项目，并把 `projectId` 写入启动意图。

# Non-goals

- 不在项目之间自动迁移文件、任务或成果。
- 不将“全部项目”作为可执行的工作上下文。
- 不改变已有任务的稳定 `projectId` 归属。

# Impact

影响工作台顶部导航、项目侧栏、工作流运行记录、管线创建与历史筛选，以及本地目录选择器。底层 Project/Source 数据模型保持不变。
