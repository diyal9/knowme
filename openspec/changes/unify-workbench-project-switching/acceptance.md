# Acceptance: unify-workbench-project-switching

## 结论

功能验收通过。工作台现在具有可见的共享项目上下文，左侧入口统一为“项目空间”，工作流与管线历史默认跟随当前项目。

## 验收结果

- [x] 在专家协作、工作流和管线服务共用顶栏切换项目
- [x] 顶部项目选择器仅负责切换，不包含打开、克隆或设置动作
- [x] 可从左侧项目菜单打开本地项目、进入 Git 仓库接入和管理项目
- [x] 左侧项目栏以文件树为主体，可切换“项目文件 / KnowMe 归档”
- [x] 不再显示重复的当前项目卡片或未接入的版本对比动作
- [x] 项目空间管理支持元数据、成果目录、重新定位和归档
- [x] “全部项目”只改变历史查看范围，不成为执行上下文
- [x] 管线创建要求一个可写项目，并在启动意图中保留 `projectId`
- [x] 切换项目不修改既有任务的持久化归属

## 门禁说明

项目栏与顶栏定向测试 22/22 通过，lint 与 renderer 类型检查通过。Renderer 全量测试 718/719 通过；唯一失败来自既有 `expert-workbench.css` 非标准字重契约。整仓 `npm run check` 在 Node 阶段被本变更之外的 Agent Registry 两项断言阻塞。
