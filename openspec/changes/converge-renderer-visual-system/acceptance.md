# 制作人验收

## 自动化验收

- `npm run visual:check`：视觉熵不高于冻结基线。
- 视觉系统契约测试：共享令牌、审计命令、结构/功能边界存在且可验证。
- 能力中心组件测试与表面 CSS 契约：卡片和入口行为不因视觉治理改变。

## 体验验收

- 能力卡片标题、元信息与说明形成清楚的三级层级，扫读速度优于改造前。
- 卡片总高度、列数、点击区域、收藏/安装操作、详情抽屉及导航关系不变。
- 页面在五秒内可回答“我在哪里、当前焦点是什么、下一步做什么”。

## 当前状态
