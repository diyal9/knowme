# QA 计划

## Smoke Scope

自动化范围：

- [x] 运行视觉预算、颜色令牌、CSS 层叠和渲染层契约测试。
- [x] 运行能力中心组件测试，核对卡片打开、收藏、安装与详情操作。
- [x] 每个迁移批次运行对应 feature 测试，不把既有失败误报为本次回归。

## 视觉矩阵

- 视口：宽屏、850px 双列、620px/窄窗。
- 状态：默认、hover、focus-visible、选中、禁用、空态、加载和错误。
- 入口：工作台、专家协作、工作流、管线、能力中心、设置。

## 回归判定

- 功能 diff 必须为 0，结构 diff 必须为 0。
- 视觉差异必须能映射到字体、留白、密度、圆角、表面或状态规则。
- 超出单一体验域的变化停止合并并另立 proposal。
