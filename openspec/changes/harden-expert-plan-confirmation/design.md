# Design

## Planning state

共享规划分析器识别计划标记、显式缺失项、补充请求和非确认型问句。任何未决项都优先于计划完整度。

## Host confirmation receipt

渲染层在用户确认时先把最后一条规划回复和规范化计划交给主进程。主进程只为完整且无未决问题的计划签发短时、一次性凭证。`createStart` 对含用户计划确认材料的新启动请求强制校验该凭证；直接创建任务和已验证任务的内部重试保持原路径。

## Delivery contract

主进程同时检查用户目标与计划交付物。生成网站、网页、落地页或 Web 系统等文件型目标必须拥有文件工具和 artifact 验收条件。Web 开发专家声明受治理的文件读写与 npm 验证工具，并把代码成果定义为文件 artifact。
