# Expert plan confirmation

## Requirements

### Mutually exclusive planning state

The system SHALL treat a planning reply with unresolved questions as clarification even when the same reply contains a complete plan.

### Host-authorized confirmation

The system SHALL require a host-issued, short-lived, single-use receipt before starting a task from a confirmed planning conversation.

### Executable Web delivery

The system SHALL require governed file tools and file artifact evidence when a confirmed Web task promises generated page or application files.
