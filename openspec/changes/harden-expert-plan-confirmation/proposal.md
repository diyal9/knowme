# Change: Harden expert plan confirmation

## Why

专家规划回复可能同时给出执行计划和未决问题。旧机制只要识别到计划字段就会显示确认入口，主进程也无法证明该计划已达到可确认状态，导致任务在信息不足时启动，甚至按纯文字交付契约空跑。

## What Changes

- 将规划回复收敛为互斥的“待澄清”或“可确认”状态。
- 在主进程签发一次性计划确认凭证，任务启动时校验计划、专家、任务和凭证一致。
- 从目标和计划推导文件交付要求，阻止网页开发任务降级成纯文字回答。
- 为 Web 开发专家开放受治理的项目文件读写与构建验证工具，所有写入仍经过草稿审批。
