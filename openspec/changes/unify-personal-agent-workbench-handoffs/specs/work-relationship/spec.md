## ADDED Requirements

### Requirement: Work is routed by relationship
The personal agent SHALL keep free co-creation in the current topic, propose an expert brief for one formal Agent delivery, and propose a workflow draft for multiple Agents or explicit orchestration.

#### Scenario: Multi-Agent request
- **WHEN** two or more Agents are requested
- **THEN** a visible workflow draft is returned for confirmation

### Requirement: Handoffs are minimal and consented
Formal handoffs SHALL include only user-selected context and SHALL exclude full personal conversations, long-term memory and credentials.

#### Scenario: Preview a handoff
- **WHEN** the personal agent proposes a formal task
- **THEN** the user can inspect the exact goal, materials and constraints before confirmation
