- [x] 验证首页先展示真实“资料/已整理知识 → 子目录 → 条目”树，目录可展开且不出现内部知识架构术语。
- [x] 添加一份 Markdown 资料，确认写入 `raw/`，树中标记“可编辑”。
- [x] 修改资料并保存，确认预览更新、重新打开内容持久化、搜索可命中新关键词。
- [x] 验证界面、Agent 和 Provider 的根库检索统一经过 `llmwiki-service`。

### 首屏三态（2026-08-10 追加）

- [ ] 空库首触：空白用户目录打开知识网，首屏为居中欢迎引导（身份「你的知识网」+ 价值/主权一句 + 放进来/AI 整理/随时查三步 + 单一主 CTA「添加第一份资料」），不出现运维台、空目录树或 LLM Wiki/Query/Ingest/Lint/qmd/raw 术语。
- [ ] 空库内联投喂：在欢迎引导内粘贴一段文字并添加，内容写入资料区；空内容给出提示且不写盘。
- [ ] 首份闭环：首份保存成功后就地出现「要我把它整理成知识吗？[整理] [以后再说]」；「整理」进入整理流程并可在「待我确认」看到结果，「以后再说」进入常态首页。
- [ ] 有资料常态：存在资料后首屏为真实索引树 + 醒目搜索；顶部搜索可命中并跳转条目；待确认存在时显示横幅直达「待我确认」。
- [ ] 知识关联入口：常态侧栏「知识关联」可打开关系视图（概念/锚点/关系边），且它不作为默认一级 Tab 出现。

## Regression Scope

- 原有 `inbox/`、根目录和 `concepts/` 条目仍可阅读与搜索。
- 知识管家任务、提案接受/拒绝、Fabric、治理、Obsidian 与远程 RAG IPC 保持可用。
- 工作台其它 rail 入口、文件编辑、Agent 对话和设置页不受影响。

## Anti-pattern Review

- 空态不得只有原因说明，必须有“添加资料”行动。
- 不得把来源切换误呈现为第二个默认知识库。
- 保存失败不得清空编辑器或显示成功状态。
- 检查失败不得伪装成“资料空间正常”。
- 窄窗口下编辑与预览不得横向溢出。
- 空库首屏不得摆运维操作台或空目录树冒充「知识网是什么」。
- 常态首页不得把 Query/Ingest/Lint 或 LLM Wiki 当作操作名/主标题。
- 「知识关联」为按需弱入口，不得升级为默认一级页面或在空库时出现干扰。
