## Why

隐藏系统标题栏后，顶栏拖拽区为空，缺少 KnowMe 产品图标与标题；工作台等内容区使用灰底与助理白底不一致，且主区左上圆角与中心覆盖层（知识网/设置等）圆角不同步，壳层观感割裂。

## What Changes

- 在窗口顶栏（titleBarOverlay 拖拽区）恢复可见的 KnowMe 品牌图标与「KnowMe」标题。
- 将工作台 / 自动化等内容画布背景统一为与助理界面相同的内容区底色（白底 `--bg-card`）。
- 统一主内容岛与中心覆盖层的左上圆角（与 `.main` 一致），避免助理 / 工作台 / 知识网切换时圆角跳变。
- 补充壳层样式回归测试，并做 Electron 冒烟确认。

## Capabilities

### New Capabilities

- `workspace-chrome-surface`: 定义工作台窗口壳层的产品品牌展示，以及各业务模式内容区背景与左上圆角的一致性约束。

### Modified Capabilities

无。

## 目标用户

- 在助理、工作台、知识网之间切换的日常用户。
- 关注品牌识别与桌面工具质感的制作人 / 设计评审。

## 验收标准

- 顶栏可见 KnowMe 图标与标题，不遮挡系统窗口按钮，仍可拖动窗口。
- 助理与工作台（及自动化）内容区外层背景色一致（助理白底）。
- 主内容区与中心覆盖层左上圆角一致；切换模式时不出现圆角有无跳变。
- 现有导航、会话 Tab、工作台 Tab、拖拽与关闭行为保持可用。
- `npm test` / `npm run lint` 通过。

## 非目标（Non-goals）

- 不恢复内容顶栏中与左侧 rail 重复的模块名（如「工作台」品牌块）。
- 不改任务栏 / 托盘图标资源，不改窗口默认尺寸。
- 不重做卡片内局部灰底（如专家属性卡、列表行），只统一内容岛外层画布。

## 商业化与体验价值

统一壳层让 KnowMe 在多模块切换时像同一产品，而不是拼装页面；顶栏品牌补回后，无系统标题时仍能一眼识别产品，有利于桌面端信任感与后续商业化包装。

## Impact

- `src/workspace.html`：顶栏品牌结构与 CSS 变量 / 主区圆角。
- `src/workbench-layout.css` / `src/workbench-console.css`：工作台画布背景。
- `tests/workbench-templates.test.js`（或新增壳层测试）：回归契约。
- 不新增 IPC、依赖或持久化。
