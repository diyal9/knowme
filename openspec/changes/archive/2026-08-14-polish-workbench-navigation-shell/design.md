## Context

工作台壳层由 `src/workspace.html` 的原生 HTML/CSS 和 `src/workspace.js` 的渲染层交互组成。当前 `.side-rail` 固定为 44px，中心覆盖层在 CSS 与 JS 中分别硬编码同一偏移；工作台顶部 `.wb-tabs-group` 使用带底色、边框和阴影的胶囊分段样式。参见 `proposal.md` 与 `specs/workspace-navigation-shell/spec.md`。

Electron 主进程只负责创建固定尺寸范围的窗口，本次不改变 `BrowserWindow` 配置。导航切换、覆盖层和工作台标签均在渲染进程完成，不新增或修改 IPC。

## Goals / Non-Goals

**Goals:**

- 让主导航在默认窗口内以图标和文字清晰表达入口。
- 用一个 CSS 自定义属性作为 rail 宽度的单一事实来源，并让 JS 从计算样式读取它。
- 将工作台与能力页的一级切换器统一为扁平下划线样式，保持 DOM 语义与事件绑定。
- 保持改动为静态 DOM/CSS 和少量现有 JS 调整，不增加启动请求、定时器或常驻对象。

**Non-Goals:**

- 不改造 Agent Session 与能力内容区筛选芯片等次级控件。
- 不改变窗口、文件侧栏、页面路由、状态持久化或 IPC 契约。
- 不引入图标库、字体或 CSS 框架。

## Decisions

### 1. Rail 使用壳层级 CSS 变量

在应用壳层定义 `--rail-width`，`.side-rail` 的 flex basis/width 与中心覆盖层 `left` 均引用该变量。JS 需要写入内联偏移时，从 `getComputedStyle(appShell)` 读取变量并回退到同一默认值。

选择该方案是为了消除多处魔法数字，避免以后再次调整宽度时 CSS 与 JS 漂移。备选方案是继续同步修改所有硬编码值，但可维护性较差。

### 2. 现有按钮内增加可见标签节点

保持按钮 ID、顺序、`title`、`aria-label` 和事件监听不变，只在图标后加入 `.rail-label`。按钮改为横向排列并扩大点击区域，激活态使用克制的中性色底板和强调色图标/文字。

该方案避免重建导航数据模型或改变 JS 绑定。窄屏下仍保留完整标签，因为 Electron 最小宽度足以容纳加宽 rail；主内容依赖现有 flex `min-width:0` 收缩。

### 3. 工作台与能力页标签保留 DOM，仅替换视觉层

`.wb-tabs-group` 与 `.drawer-capability-tabs` 移除容器背景、边框、圆角和阴影；对应标签通过伪元素绘制底部激活线，hover/focus/pressed 使用颜色和轻微位移反馈。`role=tablist`、`role=tab`、`aria-selected` 及页面切换事件不变。

选择伪元素而非 `border-bottom`，可避免激活切换时高度或基线抖动。未做全站 Tab token 重构，因为 Agent 会话与内容筛选仍有独立交互层级。

### 4. 视觉测试聚焦可观察契约

静态测试验证标签节点、rail 宽度变量、覆盖层变量引用及扁平 Tab 的关键规则；Electron 冒烟用于确认默认窗口下无重叠并记录截图。测试不锁定所有颜色像素，避免正常视觉微调造成脆弱失败。

### 5. 模块名称只由 rail 承担

rail 已持续显示模块图标和名称，因此工作台 `.wb-head-title`、能力 Hub 品牌块、知识库/设置覆盖层标题及任务协作栏中的“工作台”品牌块不再参与可见布局。顶栏容器仍保留，用于承载页面标签、刷新、关闭等操作；正文中的业务标题和上下文名称不受影响。

选择通过壳层 CSS 统一隐藏现有品牌节点，而非删除 DOM 与工作台标题同步逻辑，可将改动限制在视觉层并降低对现有事件、运行状态和兼容测试的影响。

## Risks / Trade-offs

- [Rail 加宽压缩任务双栏空间] → 保持窗口总宽不变并依赖现有 flex 收缩；在默认尺寸和最小宽度做视觉冒烟。
- [中心覆盖层仍出现偏移漂移] → CSS 统一引用变量，JS 通过统一辅助函数读取同一变量并保留安全回退。
- [文字较长导致截断] → 使用短中文名称、单行布局与固定 rail 宽度；非主要解释继续由 tooltip/aria-label 提供。
- [测试对旧胶囊样式有断言] → 只调整工作台和外层能力类型标签，不触碰 Capability Hub 内容区筛选芯片。
- [隐藏标题后顶栏出现无意义空白] → 工作台与 Hub 顶栏继续由标签填充；任务协作栏在无其他控件时整体隐藏；知识库/设置保留紧凑关闭栏。

## Migration Plan

本次仅更新静态资源，无用户数据迁移。部署后随渲染页面加载立即生效；如需回滚，恢复 `workspace.html` 的 rail/Tab 样式和 `workspace.js` 的覆盖层偏移读取即可，不影响已保存状态。
