## Why

当前左侧主导航仅显示图标，入口含义依赖 tooltip；工作台顶部使用厚重的胶囊分段控件，与用户期望的简洁桌面工具风格不一致。通过提高导航可读性并统一为扁平标签，可降低首次使用成本，让有限窗口空间中的层级更清楚。

## What Changes

- 将左侧主导航向右加宽，在保持窗口总宽不变的前提下，以“图标 + 文字”呈现主要入口。
- 左侧栏将“办公助理”的可见短标签显示为“助理”，保留入口功能与完整无障碍名称。
- 保留现有入口顺序、能力 Hub、自动化、知识库、设置及侧栏折叠行为，不改变页面功能。
- 将工作台“首页 / 工作流”胶囊分段改为无容器底色、激活项下划线的扁平标签风格。
- 将能力页“专家 / 技能 / MCP 连接器”同步改为相同的扁平文字标签与激活下划线。
- 左侧 rail 已提供模块名称时，移除工作台、能力、自动化、知识库、设置等内容顶栏中重复的模块图标与名称，仅保留页面标签、上下文标题和操作控件。
- 用统一的 rail 宽度变量同步全屏覆盖层偏移，避免导航加宽后遮挡或留缝。
- 补充导航结构与视觉约束测试，并执行 Electron 界面冒烟验证。

## Capabilities

### New Capabilities

- `workspace-navigation-shell`: 定义工作台左侧文字导航、固定窗口内的空间分配，以及工作台顶部扁平标签的可见与交互行为。

### Modified Capabilities

无。

## Target Users

- 首次使用 KnowMe、尚未熟悉图标含义的知识工作者。
- 高频在办公助理、工作台、能力与自动化之间切换的桌面端用户。

## Acceptance Criteria

- 左侧主导航主要入口始终显示图标和中文名称，窗口外框尺寸不因改版变化。
- 助理入口的侧栏短标签显示为“助理”，tooltip 与无障碍名称仍可表达完整“办公助理”含义。
- 导航加宽后，主内容区自然收缩，Capability Hub 等覆盖层从 rail 右缘开始且无重叠。
- 工作台“首页 / 工作流”保留原切换逻辑，视觉改为扁平文字标签和激活下划线。
- 能力页“专家 / 技能 / MCP 连接器”保留原切换逻辑，移除胶囊容器、绿色实心激活块和阴影。
- 进入 rail 对应模块后，内容顶栏不再重复显示该模块的图标和名称；页面级标签、正文标题、关闭与刷新操作仍可用。
- 键盘焦点、悬停、按下和激活状态清晰，现有测试、lint 与 Electron 冒烟通过。

## Non-goals

- 不重命名现有业务入口，不调整入口顺序或信息架构。
- 不改造 Agent 会话 Tab 或能力页内容区内部的筛选芯片。
- 不改变 Electron 窗口默认尺寸、侧栏文件树宽度、IPC 与持久化协议。

## Business and Experience Value

文字标签减少图标猜测和误点，帮助新用户更快理解产品能力边界；扁平导航降低视觉噪声，使工作台更接近成熟生产力工具，有利于后续承载更多技能与工作流入口而不显臃肿。

## Impact

- 渲染层：`src/workspace.html`、`src/workspace.js`。
- 测试：导航入口与工作台模板相关测试；Electron rail 视觉冒烟。
- 无新增依赖、无主进程或 IPC 变更、无数据迁移。
