# QA Plan: align-assistant-avatar-with-brand-mark

## Smoke Scope（必填）

- [ ] 打开悬浮助理面板，头像与任务栏/托盘 KnowMe 图标为同一标志，可一眼对应。
- [ ] 头像内可见四个米白节点、一个珊瑚起点，路径不交叉。
- [ ] 头像载体深蓝与圆角观感与应用图标一致，标记不贴边、不发糊。
- [ ] 悬浮触发按钮仍为铃铛，拖拽、徽标与 presence 动画不受影响。
- [ ] 面板内「日志中心」「日志目录」「继续工作」等操作行为不变。

## Regression Scope

- 悬浮助理拖拽位置持久化（`knowme.fab.pos.v2`）。
- 未读徽标与可恢复 Session 提示的显示与消失。
- presence 状态动画与 `prefers-reduced-motion` 降级。
- 深色模式下面板头像与文字对比度。

## Anti-pattern Checks（交给测试）

- 应用内标记与系统图标再次出现两套几何或两种珊瑚点位置。
- 头像圆角/配色偏离品牌，出现渐变或阴影抢焦。
- 标记缩小到 36 px 后节点粘连、线条断裂或留白失衡。
- 触发按钮被误改回品牌标记，与铃铛结论冲突。
