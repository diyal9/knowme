# QA Plan: refine-my-agent-start-handoff

## Smoke Scope（必填）

- [ ] 工作台 → 我的智能体 → 任一卡片「开始使用」→ 进入对话，首屏可见 Agent 名称 / 职责 / 来源徽标
- [ ] 「调优」仍进入智能体管理并定位到该 Agent
- [ ] 连续快速点击同一张卡片的「开始使用」两次，只产生一个会话
- [ ] 绑定飞书等未授权连接器的 Agent：会话仍可创建，首屏同时出现受限项、「仍可直接对话」与「去配置连接器」
- [ ] 界面无 emoji 头像；键盘 Tab 到卡片按钮有可见焦点环

## Regression Scope

- 通用会话（general）、知识管家、编程、写作空态首屏文案与布局无变化
- 能力页「开始使用」专家路径（`capability-hub.js`）仍可正常开聊
- 团队管线 Tab 的工作流卡片「开始 / 复制并调整 / 编辑」行为不变
- 会话 Tab 标题仍显示 Agent 名称；重启后从卡片创建的会话仍在历史里

## Anti-pattern Checks（交给测试）

- 目录接口置空（模拟 `expert.list` 抛错）后点「开始使用」：应能开聊，不得出现「点了没反应」或误报「专家不存在」
- 不存在的 expertId：只弹一条错误 toast，按钮恢复可点，用户不被留在半切换状态
- 「助手正在生成」时点「开始使用」：给出等待提示，按钮恢复，不静默失败
- 系统开启「减少动态效果」：卡片无位移与脉冲动画
- 窄窗口（≤760px）下卡片与身份区不出现横向滚动或文字截断丢失语义
- 长 Agent 名 / 长职责说明：不撑破卡片，省略要保留可读前缀
