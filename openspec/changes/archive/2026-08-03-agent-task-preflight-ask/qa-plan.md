# QA Plan: agent-task-preflight-ask

## Smoke Scope

- [ ] 未授权飞书时点「会议总结 / 今日优先级 / 查文档知识库 / 分析相关聊天」→ 只回一句话提示去授权，聊天区无 LLM 生成内容
- [ ] 已授权飞书时点上述任一卡片 → 直接调用对应 workflow 工具并给结果
- [ ] 输入框为空时点写作「写需求文档 / 写办公文档 / 按提纲成稿 / 排版定稿」→ 只回一句话询问所需素材
- [ ] 在输入框粘贴素材后直接点发送 → 自动按刚才的写作任务执行（用户气泡显示任务名）
- [ ] 输入框为空时点编程「解释代码 / 修复报错 / 实现方案 / 生成改动草案」→ 只回一句话询问代码/报错/需求
- [ ] 知识管家「检索远程知识库」输入框为空 → 一句话询问检索主题，不调用 LLM
- [ ] 快捷菜单（Ctrl/Cmd+K）触发同类任务时，缺内容/缺授权走同一套一句话询问

## Regression

- [ ] 四模式已有素材/已授权时点卡片，行为与改动前一致或更好（走增强路径）
- [ ] 知识管家 lint / promote / ingest 三项确定性动作不受影响
- [ ] 直接在输入框自由提问（不点卡片）发送不受 `pendingShortcut` 干扰
- [ ] artifact 审阅、应用到文件、飞书草稿审批链路保持可用

## Anti-pattern Checks

- [ ] 缺素材/缺授权时**绝不**产出瞎编答案（不乱说）
- [ ] 一句话询问文案由代码写死，不经 LLM，措辞稳定
- [ ] 补素材后不需要二次点击卡片即可续跑，无重复操作摩擦
- [ ] 未授权飞书时不擅自打开设置或发起授权（不乱做）
