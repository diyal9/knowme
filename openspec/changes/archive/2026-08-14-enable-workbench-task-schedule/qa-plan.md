# QA Plan: enable-workbench-task-schedule

## Smoke Scope（必填）

- [ ] 任务页「定时任务」打开任务定时面板（不进工作流自动化）
- [ ] 为最近任务设置每天/间隔/单次并保存，行上出现徽章
- [ ] 关闭计划后徽章与下次时间清除
- [ ] 模拟/等待到期：生成子任务并进入专家对话；父任务下次时间推进
- [ ] 单次计划触发后自动关闭
- [ ] 侧栏「自动化」仍可打开原工作流自动化中心

## Regression Scope

- 新建/打开普通专家任务
- 最近任务折叠「更多」
- 工作流自动化 CRUD / 立即执行（未绑管线仍有提示）

## Anti-pattern Checks

- 任务页按钮仍跳到工作流自动化
- 子任务被当成父计划再次触发
- 无提示声称关机也能触发
