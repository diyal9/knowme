# Proposal: ai-system-prompt-layers

## 一句话目标

把 AI 助手上下文升级为生产级分层架构：**产品固定底座 + 用户可填偏好 + 动态知识/记忆 + 多轮对话**，设置页不再暴露/覆盖完整系统提示词。

## 目标用户

- 日常写提示词/笔记的重度用户：希望指定专业领域与回答风格，但不想破坏产品安全与防幻觉规则
- 新用户：打开设置看到清晰引导（填领域/风格），而不是一整段难懂的系统指令

## 为什么做

当前设置页「System Prompt」**就是**整段 AI system 消息；用户可替换产品底座，导致：

1. 防幻觉 / 输出规范可被无意删掉
2. 默认文案占满输入框，不像「个人偏好」
3. 侧栏多轮对话只画在 UI 上，**未发给模型**（每次单轮）

## 做什么

1. **固定底座**（代码内、不可编辑）：身份、职责、防幻觉、输出规范
2. **用户偏好**（设置页）：专业领域、回答风格等；默认为空；与底座拼接
3. **动态层**：知识库摘要 + 使用记忆（现有）
4. **多轮历史**：侧栏近 N 轮 user/assistant 一并发送；便签正文作本轮上下文
5. **迁移**：旧默认整段 → 清空偏好；用户自定义文案 → 保留为偏好

## 非目标（Non-goals）

- 不开放修改固定底座（无「高级系统提示词」开关）
- 不引入多 agent / tool calling
- 不改 API 厂商抽象以外的计费/模型路由

## 验收标准

- 设置项文案改为「用户偏好提示词」，说明会追加到产品固定指令
- `ai-generate` 的 system = 底座 +（可选）偏好 +（可选）知识/记忆
- 连续两轮问答时，第二轮请求 messages 含第一轮
- 旧默认设置用户升级后偏好为空，助手仍可用
- `npm test` / `npm run lint` 通过
