# 制作人体验验收: establish-composable-agent-workbench

## 核心路径

- [ ] 工作台 → 切换日常办公 / 软件研发 / 视觉创作 → 页面内容与专业能力随模式变化
- [ ] 软件研发 → 选择现有工作流 → 查看 DAG → 启动或继续真实任务
- [ ] 团队 → 添加 Agent → Capability Hub 选择 Expert → 添加到当前工作台 → 返回后可见
- [ ] 团队 → 移除用户 Agent → Expert 仍保持安装且既有对话不受影响
- [ ] 重启 KnowMe → 恢复上次工作模式与团队

## 体验标准

- 用户在 10 秒内能理解“能力中心负责发现，工作台负责组队，工作流负责协作”
- 工作台首屏优先呈现当前工作方式、下一步和真实工作，不是固定专家名录
- 编码明确属于“软件研发”专业能力，日常办公和视觉创作拥有同等模式地位
- 未接通 provider、workflow 或依赖时展示诚实状态和可行动入口
- 普通用户无需理解 Daemon、Builder、IPC 等实现术语
- 所有模式、Tab、Agent 操作有键盘焦点和明确反馈
- 切换、添加和移除的感知响应小于 100ms（不含安装和远程请求）

## 非本期验收范围

- 自定义 DAG 编辑器
- 真实定时调度器
- 图像供应商接入
- 第三方工作模式市场与计费
