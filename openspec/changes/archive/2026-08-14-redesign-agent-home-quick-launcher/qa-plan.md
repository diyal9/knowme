# QA Plan

## Smoke Scope

- Agent 空会话首页仅显示四张推荐任务卡，宽屏为完整 2×2。
- 游戏工作伙伴首页单独显示“启动工作流 / 需求梳理”入口。
- 点击四张任务卡和工作流入口仍走既有授权/材料 preflight。
- Ctrl/Cmd+K 打开快捷命令面板并自动聚焦搜索框。
- 输入“会议”“文档”“优先级”“需求”等关键词可过滤到对应任务。
- 无结果时显示空状态；清空搜索恢复任务列表。
- ArrowUp/ArrowDown、Enter、Escape 可完成选择、执行、关闭。
- 打开、搜索、关闭命令面板不会修改 Composer 已有草稿。
- 动态 Skill 可检索且首页不会追加第五张卡。

## Regression Scope

- 通用、知识管家、写作、编程四模式的快捷任务仍可执行。
- 飞书未授权提示与已授权执行路径保持不变。
- 模型选择、附件、发送/停止和 Slash 菜单不受影响。
- 小窗口下命令面板不溢出，推荐卡切换为单列。

## Evidence

- 自动化：`npm test`
- 静态检查：`npm run lint`
- Electron 定向冒烟：记录命令、检查项与截图到 `evidence/`
