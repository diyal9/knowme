# QA Plan: refine-expert-detail-actions-by-surface

## Smoke Scope（必填）

- [ ] 工作台任务首页点击快捷专家卡 → 打开专家详情（非任务编排弹窗）
- [ ] 工作台详情底栏可见：开始对话、已在工作台、（精选）复制为自建
- [ ] 「+ 新建任务」仍打开「安排专家执行任务」
- [ ] 能力界面点专家 → 主按钮为添加到工作台/已在工作台；无开始对话
- [ ] 能力界面精选专家可复制为自建；自建/本地专家可调优并保存提示词

## Regression Scope

- 能力安装 / 启用 / 卸载
- 添加到工作台绑定与重复绑定
- 专家开始对话创建 Session（工作台 surface）

## Anti-pattern Checks（交给测试）

- 底栏按钮被裁切只剩一个
- 工作台点专家却弹出任务目标输入
- 能力界面误导用户「只能开始对话不能管理」
