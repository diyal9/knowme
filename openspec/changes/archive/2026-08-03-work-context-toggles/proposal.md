# 工作提示条：先下线，待产品定位

## 动机

输入框上方的工作提示 /「本轮带上」经过两轮改造后，产品定位仍不清楚：

- 做成记忆开关时，用户反馈「不理解、点了只是补一句话」
- 讨论意图推荐（去 AI 味 / 格式化 / 简单回复 / 第一性原理）时，方向又与记忆开关不同
- 制作人结论：**这一块作用还没想好，先去掉；同时先搞清记忆本身能做什么**

因此本 change 从「做开关」转向「下线 composer 提示条」，后台记忆链路保持静默注入，不因 UI 下线而切断。

## 变更

- 移除 `workspace-agent.js` 中输入框上方的工作提示条（渲染、刷新、勾选状态、本轮上下文拼装）
- 保留产品记忆后端：`capture` / patterns / consolidation / `getContextForAI` / `buildContextItems` / `personalizationContext`
- 保留设置里的【协作偏好】与已确认习惯的静默注入
- `buildWorkHints` 暂留作 API（测试与未来意图推荐可复用），但不再有 UI 消费方

## 影响

- 能力：`agent-chat-ux`（composer 旁不再展示记忆勾选条）
- 用户可见：输入框上方干净，不再出现「本轮带上」
- 不可见：记忆仍在对话请求的动态上下文中静默生效（见 acceptance / 记忆能力说明）
