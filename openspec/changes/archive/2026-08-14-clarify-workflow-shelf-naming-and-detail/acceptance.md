# 制作人体验验收: clarify-workflow-shelf-naming-and-detail

## 核心路径

- [ ] 打开工作台 → 工作流货架 → 一眼看懂卡片在办什么事（短名清晰）
- [ ] 点卡片空白 → 居中详情 → 理解能做什么 / 需要什么 / 产出什么 → 开始运行
- [ ] 点「开始」直接进确认输入；点复制/编辑图标只做该动作
- [ ] 关闭详情后仍在货架，筛选状态不丢

## 体验标准

- 响应 < 100ms 感知延迟（打开/关闭详情）
- 无多余弹窗/打扰；详情一层足够
- 视觉与现有工作台居中弹层一致，不出现侧滑抽屉
- 主按钮仍是文字「开始」，次要操作用图标但不牺牲可理解性
