# QA Plan: clarify-workflow-shelf-naming-and-detail

## Smoke Scope（必填）

- [ ] 货架卡片对管道式内部名显示结果导向短名，且不出现「（我的版本）」后缀重复
- [ ] 点击卡片空白打开居中详情弹层，内容含说明 / 输入 / 产出 / 步骤或专家 / 可运行状态
- [ ] 详情可经关闭按钮、Escape、遮罩关闭并回到货架
- [ ] 「开始」文字按钮可直接进入确认输入；编辑/复制为图标且带可访问名称
- [ ] 点「开始」或图标按钮不会误开详情

## Regression Scope

- [ ] 领域筛选与关键词搜索仍可用（内部名与短名均可搜到）
- [ ] 「我的」工作流编辑、团队工作流复制并调整仍可用
- [ ] Run 三段（确认输入 → 执行中 → 产物）与返回货架不受影响
- [ ] 管理我的工作流列表标题与货架短名一致

## Anti-pattern Checks（交给测试）

- [ ] 短名是否仍像技术管道公式（如满屏 `→`）
- [ ] 详情是否信息空洞（只有标题没有「能做什么」）
- [ ] 纯图标是否让人不知道「复制」是什么（缺 tooltip）
- [ ] 卡片是否整卡可点但按钮误触详情
- [ ] 弹层是否变成侧滑抽屉或挡住无法关闭
