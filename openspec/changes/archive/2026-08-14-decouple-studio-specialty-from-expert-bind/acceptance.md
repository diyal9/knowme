# 制作人体验验收: decouple-studio-specialty-from-expert-bind

## 闭环总则

验收必须同时覆盖：**全部调色板组件**、**正常连线路径**、**异常连线/配置拦截**、**保存→试跑（或明确失败码）闭环**。任一能力节点缺检视为未通过。

组件清单：`开始` · `结束` · `专家` · `大模型` · `工具` · `知识库` · `条件` · `汇合` · `人工确认`

## A. 组件配置矩阵

| 组件 | 正常配置 | 异常配置（必须拦截或明确提示） | 结果 |
|------|----------|--------------------------------|------|
| 开始 | 入参可编辑；可连出到能力节点 | 无能力出边仍保存时，试跑/校验给出空图或不可达提示 | ☐ |
| 结束 | 可从能力节点连入；出参可编辑 | 无入边的悬空结束不阻断保存，但图应可识别未闭合 | ☐ |
| 专家 | 选 Package + 目标；可保存试跑 | 未选 Package → `missing_agent` / 需绑定专家 | ☐ |
| 大模型 | Hub 选模型 + Prompt；**不选专家**可保存 | 未选模型 → 校验失败（非缺专家） | ☐ |
| 工具 | 选 Skill；**不选专家**可保存 | 未选 Skill → `missing_skill` | ☐ |
| 知识库 | 选知识库；**不选专家**可保存 | 未选库 → `missing_knowledge` | ☐ |
| 条件 | 左值/比较/右值；真假双端口 | 无出边 → `condition_no_out` | ☐ |
| 汇合 | 多入边汇合后出边 | 无入边时运行跳过或等待语义可解释 | ☐ |
| 人工确认 | 标题/说明；运行到此暂停 | 拒绝/超时路径有提示（若已实现） | ☐ |

## B. 连线 — 正常路径（闭环）

| ID | 路径 | 期望 |
|----|------|------|
| N1 | 开始 → 大模型 → 结束 | 保存通过；试跑不报缺专家 |
| N2 | 开始 → 工具 → 结束 | 保存通过（已选 Skill） |
| N3 | 开始 → 知识库 → 结束 | 保存通过（已选库） |
| N4 | 开始 → 专家 → 结束 | 绑定 Package 后保存/试跑 |
| N5 | 开始 → 大模型 → 条件(真→工具 / 假→结束) | 分支边可保存；编译含 condition |
| N6 | 开始 → 专家A 与 专家B → 汇合 → 结束 | 并行入汇合可表达 |
| N7 | 开始 → 专家 → 人工确认 → 大模型 → 结束 | gate 可插入串行链 |
| N8 | 开始 → 大模型 → 工具 → 知识库 → 结束 | 纯 specialty 链可保存 |

## C. 连线 — 异常路径

| ID | 操作 | 期望 |
|----|------|------|
| E1 | 自环 / A→B→A 成环 | 拒绝连线或校验报环 |
| E2 | 条件节点零出边保存/试跑 | 明确 `condition_no_out` |
| E3 | 大模型无模型仍保存 | 失败，文案含模型，**不含**「绑定专家」 |
| E4 | 工具无 Skill | `missing_skill` |
| E5 | 知识库无库 id | `missing_knowledge` |
| E6 | 专家无 Package | 需绑定本地专家 |
| E7 | 仅开始+结束、无能力节点 | 空图/请添加可执行节点 |
| E8 | 重复连同向边 | upsert 或稳定一条，不炸 UI |
| E9 | 从结束拖出 / 向开始拖入（若 UI 禁止） | 无法建立非法方向边 |
| E10 | specialty 残留旧 `agentPackageId` | 不阻保存；不要求重选专家 |

## D. Inspector / 卡片字段抽检

- [ ] 大模型：名称、模型(Hub)、温度、Prompt；**无**执行专家
- [ ] 工具：名称、Skill、目标；**无**执行专家
- [ ] 知识库：名称、知识库、检索目标；**无**执行专家
- [ ] 专家：执行专家必有
- [ ] 调色板 hint：大模型不暗示「必须绑专家」

## 体验标准

- 错误说人话：缺什么说什么（模型/技能/库/专家），不张冠李戴
- 正常路径可「配置 → 连线 → 保存 → 试跑」闭环
- 无多余弹窗；控制台无业务 uncaught
