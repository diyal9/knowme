# QA Plan: decouple-studio-specialty-from-expert-bind

## Smoke Scope（必填）

按组件全覆盖；每条须记录 PASS/FAIL。详细矩阵见 `acceptance.md`。

### 组件配置

- [ ] 开始 / 结束：入参出参可编辑
- [ ] 大模型：Hub 选模型 + Prompt，不选专家可保存
- [ ] 工具：仅选 Skill 可保存
- [ ] 知识库：仅选库可保存
- [ ] 专家：未选 Package 拦截；选后可通过
- [ ] 条件 / 汇合 / 人工确认：属性可编辑

### 正常连线闭环

- [ ] N1 开始→大模型→结束（试跑不报缺专家）
- [ ] N2 开始→工具→结束
- [ ] N3 开始→知识库→结束
- [ ] N4 开始→专家→结束
- [ ] N5 大模型→条件真假分支
- [ ] N6 双专家→汇合→结束

- [ ] E2 条件无出边
- [ ] E3 大模型无模型（非缺专家文案）
- [ ] E4 工具无 Skill
- [ ] E5 知识库无库

- 模型仍只能手打、假 Hub
- 工具/知识库偷偷要专家才能跑
- 调色板文案暗示必绑专家

- 超长 Prompt / 特殊字符节点名
