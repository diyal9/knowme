# QA Plan: launch-dialog-progressive-disclosure

## Smoke Scope（必填）

- [ ] 打开「文档到实施计划」启动弹窗：首屏无完整 DAG 半屏，可见步数摘要与「查看执行流程」
- [ ] 点击展开后可见分支/门禁节点；收起后回到摘要且表单内容保留
- [ ] 工程上下文字段默认折叠；展开可编辑；开始任务仍可提交

## Regression Scope

- [ ] 本地（非 Daemon）工作流启动弹窗同样走摘要/展开
- [ ] 任务工作间运行时节点状态回写不受影响
- [ ] 小屏宽度下摘要与展开均可滚动、无遮挡页脚按钮

## Anti-pattern Checks（交给测试）

- [ ] 摘要文案是否仍出现内部节点 ID 堆叠造成二次过载
- [ ] 「查看执行流程」是否被藏得过深 / 对比度不足
- [ ] 折叠区是否让必填 PRD 路径难以发现（若该工作流强依赖）
