# QA Plan: add-workbench-dialogue-status-bar

## Smoke Scope（必填）

- [ ] 专家协作 → 打开任务对话房 → 左栏顶有标题 + 返回；返回回到列表
- [ ] 工作流货架 → 打开对话房 → 左栏顶有工作流短名/目标 + 返回；返回回货架
- [ ] Daemon 运行审阅（有左对话）→ 顶栏有阶段/运行身份；右栏「返回」仍可用且无三重返回混乱
- [ ] 工作台总览（专家首页 / 货架）→ 不出现对话状态栏
- [ ] 窄窗下标题省略、不横向溢出；控制台无新增报错

## Regression Scope

- [ ] 助理模式 Session Tab / 历史 / 更多仍可用
- [ ] 工作流运行 `#wbRunBack`、Outcome Pill、无步进条回归（simplify-workflow-run-topbar）
- [ ] 专家任务房右栏内容（需要/产出/开始运行）仍可用
- [ ] `npm test` / `npm run lint` 通过

## Anti-pattern Checks（交给测试）

- [ ] 顶栏是否像不可点的装饰控件（假按钮）
- [ ] 左右「返回」行为是否不一致或连续点两次才退出
- [ ] 标题是否长期显示空泛「工作台」「当前工作」而无具体任务身份
- [ ] 滚动对话后顶栏是否消失或遮挡首条消息过多
