## Why

编排画布摘要卡目前仅用顶部 3px 色条区分类型，头栏仍是浅灰渐变，正文标签与取值几乎同权，扫读时类型辨识弱、关键配置（技能/知识库/未绑定等）不够醒目。用户反馈卡片「不够精美」，需要用类型配色强化顶栏，并突出正文重点。

## What Changes

- 画布节点头栏改为**全宽类型主题色底**（工具金棕、知识青、大模型靛、专家绿等），图标/标题/操作按钮在色带上可读
- 去掉仅靠顶边细线区分类型的弱提示；选中态仍保留蓝描边，不与类型色冲突
- 正文摘要行拉开层次：标签弱化、取值加粗；未配置/警示项用类型色或 warn 色强调；已配置主值用更深正文字色
- 保持只读摘要卡职责不变（编辑仍在右侧属性面板）

## 目标用户

编排工作流的作者：需要一眼识别节点类型，并快速扫到「绑了什么 / 缺什么」。

## 验收标准

- 工具 / 知识库 / 大模型 / 专家 / 条件等节点头栏为对应主题色全宽条，非仅顶边细线
- 正文「未选择技能 / 未绑定专家」等关键空态明显醒目；已填主值比标签更突出
- 选中蓝框与类型色头栏可同时存在且不糊成一片
- 节点仍为只读摘要，无新增卡片内编辑控件
- 不影响端口连线、拖拽与属性面板编辑

## 非目标（Non-goals）

- 不改 runtime / 校验 / Inspector 字段结构
- 不引入第三方组件库或重做整套画布视觉
- 不改轻量步骤列表模式卡片
