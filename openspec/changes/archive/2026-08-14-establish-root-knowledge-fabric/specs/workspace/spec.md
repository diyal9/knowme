# workspace

## ADDED Requirements

### Requirement: Knowledge fabric UI

The knowledge center SHALL provide dedicated Fabric and Retrieve tabs with actionable empty states.

#### Scenario: Open fabric tab

- **WHEN** user opens knowledge center Fabric tab
- **THEN** graph stats, node/edge lists, and weave actions are shown

#### Scenario: Retrieve with provenance

- **WHEN** user searches on the Retrieve tab
- **THEN** hits show source library tag, authority, and conflict warnings when present
