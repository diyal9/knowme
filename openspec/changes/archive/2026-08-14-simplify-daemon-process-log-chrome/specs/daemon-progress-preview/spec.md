## MODIFIED Requirements

### Requirement: 过程分区可折叠

Daemon 审阅「过程日志」Tab 中，「过程」与「运行日志」区块 MUST 支持通过点击文件头折叠或展开正文。折叠控件 MUST 仅以图标表示展开/收起状态（MUST NOT 显示「展开」「收起」文字）。同一次任务会话内，折叠状态在日志增量重绘后 MUST 被保留。「过程」分区 MUST 默认展开。收起的「过程」文件头 MUST 贴靠面板顶部；收起的「运行日志」文件头 MUST 贴靠面板底部；展开分区 MUST 占据剩余高度。

#### Scenario: 点击文件头折叠

- **WHEN** 用户点击「过程」或「运行日志」文件头
- **THEN** 对应正文隐藏或显示，文件头仍可见，且仅以图标表达折叠状态

#### Scenario: 重绘保留折叠

- **WHEN** 运行日志有增量且触发过程日志重绘
- **THEN** 用户此前折叠的分区保持折叠

#### Scenario: 默认展开过程

- **WHEN** 用户首次打开某任务的过程日志 Tab
- **THEN** 「过程」分区为展开状态

#### Scenario: 收起贴边

- **WHEN** 「过程」收起且「运行日志」展开（或相反）
- **THEN** 收起分区的文件头分别贴顶或贴底，展开分区占满剩余空间

### Requirement: 过程区仅预览

「过程」正文 MUST 以安全 Markdown 预览展示。界面 MUST NOT 提供预览/源码视图切换入口。

#### Scenario: 默认预览

- **WHEN** 用户打开含非空 progress 文本的过程日志 Tab
- **THEN** 「过程」区以预览排版展示，且无「预览」「源码」切换控件
