## MODIFIED Requirements

### Requirement: 结束态结果页标题层级对齐右栏

管线/工作流运行结束态结果区 MUST 在内容顶部展示堆叠标题。管线（Daemon）结束态小标题 MUST 为「管线」，主标题 MUST 为 `Daemon 阶段 · {目的标题}`，MUST NOT 因关联管线定义而标成「工作流」。本地/货架工作流结束态：有工作流显示名时小标题为「工作流」、主标题为工作流名；否则小标题为「任务」。产物列表（或空态说明）上方 MUST 另有次级小标题「产物」；当存在可展示产物条目时，次级小标题 MUST 包含条目数量（例如「产物（2）」）。

#### Scenario: 管线结束态不标「工作流」

- **WHEN** 管线（Daemon）任务进入结束态结果页
- **THEN** 结果区小标题为「管线」
- **AND** 主标题为 `Daemon 阶段 ·` 开头的目的标题

#### Scenario: 工作流结束态显示小标题 + 主标题

- **WHEN** 本地/货架工作流运行进入结束态且关联工作流可解析显示名
- **THEN** 结果区顶部显示小标题「工作流」与该工作流名主标题

#### Scenario: 有产物时显示带数量的次级小标题

- **WHEN** 运行进入结束态且存在至少一个可展示产物
- **THEN** 产物列表上方显示「产物（N）」次级小标题（N 为可展示条目数）

#### Scenario: 无产物时仍保留次级小标题

- **WHEN** 运行进入结束态且没有可展示产物
- **THEN** 仍显示「产物」次级小标题，并在其下展示空态说明文案
