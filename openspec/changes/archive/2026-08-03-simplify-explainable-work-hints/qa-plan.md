# QA Plan: simplify-explainable-work-hints

## Smoke Scope（必填）

- [x] 输入框为空且存在工作提示时，默认只显示带复选框的简短推荐名，不常驻「具体内容 / 为什么推荐」
- [x] 鼠标悬停推荐项 → 浮层同时显示具体内容与推荐原因
- [x] 键盘聚焦复选框 → 浮层与悬停内容一致
- [x] 勾选推荐项 → 内容填入输入框，仍可编辑，不自动发送
- [x] 点「隐藏」→ 整组提示消失；输入中或运行中提示条不展示

## Regression Scope

- [x] 推荐生成仍最多 3 条，且仍依赖既有 memoryInsights / payload
- [x] 会话恢复建议（「依据：已有 Session 摘要」）不受影响
- [x] 输入框自由提问、发送、流式回复链路保持可用
- [x] 工作台与 Agent 模式共用 composer 时提示条不破坏布局

## Anti-pattern Checks（交给测试）

- [x] 未勾选时不得自动填入或发送
- [x] 详情默认隐藏，避免抢占输入区注意力
- [x] 长文案在浮层内可换行，不撑破输入区
- [x] 隐藏后本会话不再反复弹出同组提示
