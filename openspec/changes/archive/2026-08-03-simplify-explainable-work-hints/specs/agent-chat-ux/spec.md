## ADDED Requirements

### Requirement: 工作提示可选择且按需解释
系统 SHALL 将基于记忆或工作上下文生成的工作提示展示为紧凑、可勾选的选项；默认状态 SHALL 只显示简短名称，用户悬停或键盘聚焦时 SHALL 显示将采用的具体内容及推荐原因。

#### Scenario: 默认仅展示简洁选项
- **WHEN** 输入框为空且系统存在可用工作提示
- **THEN** 系统显示带未选中状态的简短推荐项
- **THEN** 系统不常驻显示具体内容或推荐依据

#### Scenario: 悬停查看推荐解释
- **WHEN** 用户将鼠标悬停在某条推荐项上
- **THEN** 系统显示该推荐将填入的具体内容
- **THEN** 系统显示该推荐对应的来源或推荐原因

#### Scenario: 键盘聚焦查看推荐解释
- **WHEN** 用户通过键盘将焦点移到某条推荐项
- **THEN** 系统显示与鼠标悬停一致的具体内容和推荐原因

#### Scenario: 勾选应用推荐
- **WHEN** 用户勾选某条推荐项
- **THEN** 系统将该推荐内容填入输入框
- **THEN** 填入内容保持可编辑且不会自动发送
