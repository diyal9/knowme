## ADDED Requirements

### Requirement: 团队空状态可继续

工作台团队页在当前模式没有任何内置角色或用户绑定 Agent 时，MUST 展示可理解的引导和可执行入口。

#### Scenario: 空团队提供组队动作

- **WHEN** 用户进入没有成员的团队页
- **THEN** 页面展示当前模式的组队说明、一个“添加 Agent”动作和一个“浏览能力中心”动作
- **AND** 点击“添加 Agent”复用现有 Agent 选择路径
- **AND** 点击“浏览能力中心”复用现有能力中心技能路径

### Requirement: 高级模式菜单完整可见

工作台高级模式菜单 MUST 在默认窗口和窄窗口下保持完整可见、可聚焦和可操作。

#### Scenario: 展开高级菜单

- **WHEN** 用户点击“高级”
- **THEN** “工作方式”标签和模式选择器完整出现在菜单中
- **AND** 菜单不被工作台头部裁切
- **AND** 原生模式选择器仍可通过键盘聚焦和切换

### Requirement: 既有团队行为保持稳定

团队优化 MUST NOT 改变已有成员展示、添加、移除和模式切换行为。

#### Scenario: 已有成员继续展示

- **WHEN** 当前模式存在内置角色或已绑定 Agent
- **THEN** 页面继续按既有分组渲染成员卡片
- **AND** 添加 Agent、移除 Agent 和模式切换使用原有事件与数据协议
