# QA Plan: restore-unified-knowme-brand-icon

## Smoke Scope（必填）

- [x] Windows 托盘图标与相邻图标视觉尺寸一致，不显著偏小。
- [x] 16 px 下深蓝载体、米白连接路径和珊瑚起点清晰可辨，无明显糊边。
- [x] Windows 125%/150% 缩放下使用 2× 表示，不放大低清 16 px 位图。
- [x] 标题栏和任务栏使用更新后的同构图标，四边不裁切。
- [x] 重启后新图标立即生效，无需手动清除系统缓存。

## Regression Scope

- 主 `icon.png`、ICO 全尺寸帧与托盘使用同一五节点连接构图。
- Windows ICO 继续包含 16/24/32/48/64/128/256 px 帧。
- SVG 源文件与确定性 Pillow 生成器保持同构。
- 托盘点击、菜单和窗口恢复行为不受影响。

## Anti-pattern Checks（交给测试）

- 便签尾巴、后层卡片或可读 KM 字母重新出现。
- 节点超过五个、路径交叉或珊瑚色出现多个焦点。
- 外部留白过大导致图标视觉偏小。
- 由高分辨率资源重复缩放造成节点和斜线发糊。
- 深色与浅色任务栏下出现边缘脏色或低对比度。
