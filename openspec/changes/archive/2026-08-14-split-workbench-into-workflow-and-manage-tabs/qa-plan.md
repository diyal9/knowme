# QA Plan

## Smoke Scope

- [ ] 进入工作台默认停在「工作流」Tab，顶栏右侧无「管理」下拉按钮
- [ ] 货架筛选行无「新建工作流」，空货架时空态里仍可新建
- [ ] 「管理」Tab 是常驻面（非右滑抽屉），二级分区依次为工作流 / 执行后端 / 自动化，默认停在工作流
- [ ] 管理 Tab 工作流分区列出全部「我的」工作流，可编辑（进编排）与删除
- [ ] 删除一条我的工作流后，切回「工作流」Tab 货架上同步消失
- [ ] 没有个人工作流时空态给出新建 / 去货架复制两个可点击入口
- [ ] 切「管理」Tab 搜索框隐藏，切回「工作流」搜索词仍在
- [ ] 进运行页 / 编排页两 Tab 隐藏，返回后恢复

## Regression Scope

- [ ] 执行后端（Daemon）面板与自动化面板内容、交互不回归
- [ ] 从设置页 / 通知跳转 `daemon`、`automation` 仍直达对应分区
- [ ] 运行三段式（确认输入 → 执行中 → 产物）、返回与重启恢复不回归
- [ ] 编排保存后工作流以「我的」标签即时进货架
- [ ] 旧存档遗留状态不导致空白或报错
- [ ] 窄窗(760px)与 900px 断点下 Tab、管理面、工作流列表不破版

## Anti-pattern Review（测试角色重点）

- [ ] 「管理」是否还残留任何抽屉式浮层痕迹（半覆盖、点外部关闭等混合语义）
- [ ] 删除工作流是否有二次确认，是否会误删团队工作流
- [ ] 两 Tab 与运行/编排页的返回是否出现两套返回语义
- [ ] 管理面滚动是否与工作台整体滚动打架

## Automated Checks

- [ ] `npm test`
- [ ] `npm run lint`
- [ ] `npx openspec validate split-workbench-into-workflow-and-manage-tabs --strict`
- [ ] Electron 冒烟脚本
