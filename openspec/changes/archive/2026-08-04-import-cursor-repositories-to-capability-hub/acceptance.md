# 制作人体验验收: import-cursor-repositories-to-capability-hub

## 核心路径

- [x] 能力 Hub 的添加对话框可发现“Cursor 仓库”，入口文案说明扫描范围与安全边界
- [x] 切换来源后展示独立选择入口，未扫描时“确认注册”保持禁用
- [x] 三个真实仓库均能稳定扫描并注册到当前 KnowMe 用户数据
- [x] Hub catalog 可读取 4 个仓库专家与 30 个仓库技能
- [x] 重名技能使用稳定仓库前缀，不覆盖既有能力
- [x] 不支持的 MCP 配置给出警告并跳过，不阻断专家和技能

## 体验标准

- 用户从一个入口完成仓库级接入，无需逐个复制 SKILL.md
- 预览、确认、部分失败反馈形成闭环，不把失败伪装成成功
- 能力卡片明确标记“Cursor 仓库”来源，失效路径有诚实状态
- 扫描只在用户操作时发生，不增加应用启动负担
- UI 与当前能力 Hub 的克制浅色设计一致，无新增打扰弹窗

## 商业化与产品价值

- 降低存量团队智能体资产迁入 KnowMe 的成本，增强首次价值感与留存
- 仓库级来源为后续团队能力包、版本更新和企业连接器治理提供统一模型
- 链接而非复制避免资产分叉，适合作为专业团队版能力管理基础
