# Proposal: favorite-to-footer

## 一句话目标

便签编辑窗的收藏星标从顶栏移到底部状态栏，与编辑/元信息操作同区。

## 目标用户

边写边标记重要提示词的用户；顶栏空间留给窗口控制。

## 为什么做

顶栏已有置顶 / 最小化 / 关闭；收藏属于内容属性，放在底栏更贴近「全文/分段 / 保存态」，减少顶栏拥挤。

## 做什么

1. 移除顶栏收藏按钮
2. 在底部状态栏（模式切换旁）放置同一星标，保持收藏切换逻辑不变

## 非目标

- 不改收藏持久化 / IPC
- 不改总览列表收藏交互

## 验收标准

- 顶栏无星标；底栏可见星标，点击可收藏/取消
- 收藏状态（亮/空心）与总览一致
- `npm test` / `npm run lint` 通过
