## MODIFIED Requirements

### Requirement: 结束态结果页排版对齐对话右栏

管线/工作流运行结束态结果区 MUST 在视觉上对齐对话右栏工作流卡（`.wb-side-workflow`）的标题层级、边距与分割线。小标题与分区标题 MUST 使用深色字重（对齐 `.wb-side-panel-head strong`），MUST NOT 使用 muted 作为分区主标题色。标题区与「产物」分区之间 MUST 有水平分割线，颜色 MUST 使用与右栏区块相同的边框 token。结果区内边距 MUST 与右栏面板水平节奏一致。

#### Scenario: 标题区与产物区有分割线

- **WHEN** 用户进入结束态结果页
- **THEN** 堆叠标题区与「产物」分区之间可见水平分割线
- **AND** 分割线左右与内容对齐（inset，非贴满外框）

#### Scenario: 产物分区标题对齐「需要」

- **WHEN** 结果页展示「产物」或「产物（N）」
- **THEN** 该分区标题字色与字重对齐右栏「需要」小标题（深色加粗）

#### Scenario: 小标题与主标题对齐右栏

- **WHEN** 结果页展示「管线」或「工作流」小标题与主标题
- **THEN** 小标题与主标题的字号/字重/颜色对齐右栏「工作流」与工作流名
