## Why

工作台「任务」首页的「你的任务」默认展开全部最近任务，任务一多就会把快捷入口挤出首屏，用户需要反复滚动才能看到完整布局。需要默认折叠、点「更多」再展开，并保留上下滚动能力。

目标用户：日常使用工作台安排专家任务、频繁回看最近任务的桌面用户。

商业化与体验价值：首屏一次看清「快捷任务 + 最近任务摘要」，降低认知负荷；展开后仍可流畅浏览完整历史，提升任务恢复效率。

## What Changes

- 「你的任务」默认只显示有限条数，使任务首页在常见窗口高度下一屏看完。
- 超出预览条数时提供「更多 / 收起」切换，点击后展开或折叠其余任务。
- 展开后任务列表（及任务首页容器）支持上下滚动浏览完整列表。
- 不改变任务数据模型、打开任务逻辑或快捷任务入口行为。

验收标准：

- 任务数 ≤ 预览条数时不显示「更多」，列表完整展示。
- 任务数 > 预览条数时默认只显示预览条数，首屏可见快捷任务与最近任务摘要。
- 点击「更多」展开全部；点击「收起」回到预览。
- 展开后可通过滚动浏览超出视口的任务行。
- 打开任务、空态文案、自动化入口行为不变。

非目标（Non-goals）：

- 不改任务持久化、IPC 或状态机。
- 不做分页 API / 服务端分页。
- 不改快捷任务卡片布局与筛选规则。
