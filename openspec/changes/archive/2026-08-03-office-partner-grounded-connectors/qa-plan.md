# QA Plan: office-partner-grounded-connectors

## Smoke Scope

- [ ] 飞书连接器关闭时，相关提示明确指向“启用连接器”，而不是笼统说读不到工具
- [ ] 飞书连接器已启用但 user 未授权时，相关提示明确指向“完成 user 授权”
- [ ] 飞书连接器已授权但 allowlist 未放行时，相关提示明确指向 allowlist 缺口
- [ ] 用户输入飞书文档链接后，系统先读取正文，再进入润色/改写，而不是直接编造成果
- [ ] 可以新增并浏览一个 GitHub 仓库内容源，读取仓库文本文件
- [ ] 可以新增并浏览一个网页内容源，读取抽取后的正文
- [ ] 润色改写时能利用知识库 / RAG / active source 资料增强上下文，输出更专业的版本
- [ ] 长文仍可进入右侧审阅，并生成飞书文档草稿

## Regression

- [ ] 现有本地目录与 GitLab 内容源不受影响
- [ ] 现有飞书 `doc_kb_suggest`、`search_docs`、`read_doc` 链路不回退
- [ ] 现有远程 RAG / MCP 连接器投影仍可工作
- [ ] 普通短文润色不会被强制提升为重型多源检索工作流

## Anti-pattern Checks

- [ ] 不会把“工具未授权”和“本轮缺少正文证据”混成同一句提示
- [ ] 不会把网页/GitHub 检索片段直接写成已确认事实
- [ ] 润色后的专业文稿不会因为去 AI 味而丢失术语、边界或事实出处
