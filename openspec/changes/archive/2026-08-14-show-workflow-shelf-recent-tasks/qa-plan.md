# QA Plan: show-workflow-shelf-recent-tasks

## Smoke Scope（必填）

- [ ] 工作流 Tab：货架下方出现「工作流任务」区
- [ ] 从货架启动工作流后，该任务出现在下方列表；点击可恢复对话房
- [ ] 无工作流任务时显示空态
- [ ] 任务 Tab「最近任务」不再显示带工作流的任务
- [ ] 任务数 > 3 时默认预览，「更多/收起」可用
- [ ] 工作流卡片默认只显示一行；点「更多」展开，默认首页无页面滚动

- [ ] 货架筛选 / 搜索 / 管理工作流入口不受影响
