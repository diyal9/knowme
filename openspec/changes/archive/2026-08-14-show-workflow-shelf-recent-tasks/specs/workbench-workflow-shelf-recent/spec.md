# workbench-workflow-shelf-recent

## ADDED Requirements

### Requirement: 工作流货架下方展示工作流任务

「工作流」Tab 的货架页面 MUST 在工作流卡片网格下方展示「工作流任务」区，列出带非空 `workflowId` 的持久化任务。展示与打开行为 MUST 对齐任务 Tab「最近任务」（状态点、摘要、相对时间、点击恢复）。

#### Scenario: 货架下方可见工作流任务

- **WHEN** 用户打开「工作流」Tab 且存在至少一条 `workflowId` 非空的任务
- **THEN** 货架卡片下方显示「工作流任务」列表
- **AND** 每条任务可点击打开并恢复对应 Session / 对话房（若仍可得）

#### Scenario: 无工作流任务空态

- **WHEN** 用户打开「工作流」Tab 且没有带 `workflowId` 的任务
- **THEN** 显示空态提示（引导从上方货架开始任务）
- **AND** MUST NOT 渲染虚假任务行

#### Scenario: 默认折叠预览

- **WHEN** 工作流任务数超过预览条数
- **THEN** 默认只展示预览条数，并提供「更多 / 收起」
- **WHEN** 任务数不超过预览条数
- **THEN** 完整展示且不显示「更多」

### Requirement: 货架卡片默认一行可展开

「工作流」Tab 货架卡片网格 MUST 默认只展示一行（按当前栅格列数计算），超出时提供「更多 / 收起」。默认折叠态下工作流首页 MUST 在常见窗口高度内一屏可读完，MUST NOT 依赖页面滚动；展开货架或工作流任务「更多」后 MAY 允许滚动浏览。

#### Scenario: 默认只显示一行工作流

- **WHEN** 可展示工作流数量大于一行容量
- **THEN** 默认只渲染一行卡片，并显示「更多」
- **WHEN** 用户点击「更多」
- **THEN** 展开全部卡片，页面可滚动

#### Scenario: 一行内无需更多

- **WHEN** 可展示工作流数量不超过一行
- **THEN** 完整展示且不显示货架「更多」
