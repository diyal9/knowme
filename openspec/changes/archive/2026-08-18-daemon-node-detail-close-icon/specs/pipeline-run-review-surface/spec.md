## ADDED Requirements

### Requirement: 节点详情以右侧关闭图标退出

管线审阅节点详情视图 MUST 在内容区右上角提供关闭图标控件（非左侧「返回步骤」文案）。用户激活该控件后 MUST 退出详情并回到步骤列表。控件 MUST 具备可读名称（如 aria-label「关闭详情」）。详情区 MUST NOT 再展示「返回步骤」文案按钮。

#### Scenario: 右上角关闭回到列表

- **WHEN** 用户在节点详情中点击右上角关闭图标
- **THEN** 审阅「步骤」区回到步骤微卡列表

#### Scenario: 无返回步骤文案

- **WHEN** 用户打开任一节点详情
- **THEN** 界面不显示「返回步骤」文案，关闭入口在右侧以图标呈现
