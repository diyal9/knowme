# QA Plan: workbench-expert-detail-direct

## Smoke Scope（必填）

- [ ] 工作台任务首页点击快捷专家卡 → 直接出现专家二级详情弹窗，背后仍是工作台（非能力 Hub 整页）
- [ ] 工作台详情底栏仅有「开始对话」（或启用/安装并开始）
- [ ] 关闭详情 / 点遮罩 / Esc → 回到工作台
- [ ] 「开始对话」成功后叠层关闭并进入对话
- [ ] 「+ 新建任务」仍打开任务编排
- [ ] 能力界面点专家 → 能力 Hub + 管理向底栏（添加到工作台等），无「开始对话」

## Regression Scope

- 能力安装 / 启用 / 卸载
- 添加到工作台绑定
- 能力 rail 打开/关闭 Hub

## Anti-pattern Checks（交给测试）

- 工作台点专家仍先闪一下能力目录
- 工作台详情仍露出「已在工作台 / 复制为自建」
- 透明叠层导致点击穿透或无法关闭
