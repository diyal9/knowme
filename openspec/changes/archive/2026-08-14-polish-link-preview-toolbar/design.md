## Context

链接预览位于 Electron 渲染进程的工作面中。`workspace.html` 同时承载工具栏结构与样式，`ui-icons.js` 以本地 SVG path 提供统一的线性图标；按钮行为由 `workspace.js` 绑定。现有操作组容器增加了背景、边框和内边距，三个按钮复用了语义偏弱或与窗口控制重复的通用图标。

## Goals / Non-Goals

**Goals:**

- 用最小渲染层改动减轻操作组视觉重量。
- 为三个操作提供可复用、命名明确且与当前 Lucide 线性规范一致的 SVG 图标。
- 保持按钮 DOM、事件绑定、提示文案和可访问性属性稳定。

**Non-Goals:**

- 不改变链接解析、`webview`、外部打开白名单或全屏状态模型。
- 不改主进程、预加载脚本或 IPC。
- 不引入第三方图标依赖或异步资源加载。

## Decisions

### 1. 仅移除操作组容器装饰

将操作组保留为 `inline-flex` 布局，只清除背景、边框和内边距，继续沿用按钮级 hover/active 反馈。相比删除容器节点，这能避免修改 DOM 查询、布局语义或测试定位，同时实现截图所需的干净效果。

### 2. 在现有本地图标表增加三个专用图标

新增 `maximize`、`externalLink` 和 `circleX`，使用与现有 24×24 Lucide 图标相同的描边属性。相比复用 `expandText`、`link` 和 `close`，专用图标更准确；相比引入图标包，本地 path 不增加启动 I/O、依赖体积或内存驻留。

### 3. 不修改行为层

HTML 仅替换 `data-icon`，按钮 ID 保持不变，因此 `workspace.js` 的全屏、外部打开、复制和返回逻辑无需改动。主进程/渲染进程/IPC 边界完全不变。

## Risks / Trade-offs

- [圆圈关闭仍包含叉号，可能被理解为通用关闭] → 圆形边界与窗口标题栏裸叉号形成明确区分，并由“关闭预览”提示补足语义。
- [去掉组容器后按钮边界变弱] → 保留现有单按钮悬停底色、按下位移和可访问标签。
- [新增图标影响全局图标挂载] → 仅向现有静态映射增加键值，不改变挂载算法，并用回归测试验证引用存在。

## Migration Plan

直接随渲染资源发布，无数据迁移。回滚时恢复三个 `data-icon` 引用和操作组的四条装饰样式即可。
