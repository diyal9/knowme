# QA Plan

## Smoke Scope

- [ ] 打开一条飞书文档链接进入内置浏览器，确认操作按钮组没有独立底色、描边或胶囊轮廓。
- [ ] 确认全屏为四角最大化图标、飞书打开为方框外跳图标、关闭预览为圆圈关闭图标，复制图标保持不变。
- [ ] 依次点击全屏/退出全屏、在飞书打开、复制链接、关闭预览，确认行为与改动前一致。
- [ ] 键盘聚焦四个按钮，确认可见焦点和准确的 `aria-label`；悬停与按下反馈正常。
- [ ] 打开非飞书网页链接，确认外部打开图标和提示文案仍适配浏览器语义。

## Regression Scope

- [ ] 普通文档工作面、产物审阅和工作台页面不显示链接预览专属操作。
- [ ] 窗口右上角最小化/关闭图标与行为不受影响。
- [ ] 内置 `webview` 尺寸、圆角、全屏 Esc 退出和链接安全策略不受影响。
