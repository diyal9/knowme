## MODIFIED Requirements

### Requirement: Studio layout prioritizes the canvas

The Studio surface SHALL fill the workbench body without large outer margins. The node library SHALL use a fixed narrow width so the canvas remains the primary working area.

### Requirement: Canvas node operations

Users SHALL be able to remove non-start/end canvas nodes via an on-node control, a context menu, or the Delete/Backspace key when a node is selected. Start and end nodes MUST NOT be removable. Selected edges SHALL be removable via Delete/Backspace or the context menu.
