# 制作人体验验收: connect-expert-hub-to-chat

## 核心路径

- [ ] 能力 Hub → 专家详情 → 单击主按钮 → 独立专家对话可输入
- [ ] 专家未安装或停用时无需安装后再次寻找/点击入口
- [ ] 新专家对话不污染进入 Hub 前的对话与草稿
- [ ] 专家欢迎区能回答“当前是谁、能做什么、什么暂不可用”
- [ ] 依赖未授权时可继续普通对话，并能一键进入对应配置
- [ ] 重启后可继续该专家对话，persona 与能力快照保持一致

## 体验标准

- 主 CTA 点击后立即进入 loading/disabled 状态，避免重复创建
- 本地准备完成后的导航反馈无明显停顿
- 错误提示说明失败步骤和下一步，不显示虚假成功
- 专家身份持续可辨识但不挤压主要聊天内容
- 不新增多余弹窗，不要求用户理解 Session、快照或 binding 技术概念

## 商业化与留存观察

- 能力 Hub 的浏览行为能够转化为真实对话启动
- 专家复用入口与历史会话可提高长期工作伙伴心智
- 依赖降级减少首次使用阻塞，同时保持连接器授权与高风险能力边界
