# QA Plan: connect-expert-hub-to-chat

## Smoke Scope（必填）

- [ ] 已安装启用专家点击“开始对话”后，Hub 关闭并激活独立专家 Session
- [ ] 未安装专家点击“安装并开始”后一次完成安装与进入对话
- [ ] 已停用专家点击“启用并开始”后一次完成启用与进入对话
- [ ] 专家空状态展示身份、建议任务、能力就绪摘要并聚焦输入框
- [ ] 缺少连接器授权时仍可普通对话，受限工具不可执行且可进入配置
- [ ] 重启应用后专家 Session 与创建时快照可恢复

## Regression Scope

- [ ] 技能与 MCP 连接器的安装、更新、启停、卸载行为不变
- [ ] 普通 Session 新建、切换、关闭、历史和草稿隔离不变
- [ ] 专家选择弹层仍能创建专家 Session
- [ ] 能力 Hub 搜索、分类、已安装筛选与关闭入口正常
- [ ] 连接器 allowlist、风险确认及写入审批没有被绕过

## Error / Boundary Scope

- [ ] 安装失败时 Hub 保持打开并显示真实错误
- [ ] Session 创建失败时不关闭 Hub、不新增空 Tab
- [ ] 非当前 Hub frame 的伪造启动消息被忽略
- [ ] 连续快速点击主 CTA 不创建重复 Session
- [ ] 专家后来更新、停用或卸载时，旧 Session persona 不漂移且失效工具被排除

## Anti-pattern Checks（交给测试）

- [ ] 不出现“点击无反应”、虚假成功 toast 或需要二次寻找聊天入口
- [ ] 不在 Hub 抽屉内再嵌入窄聊天窗口
- [ ] 不用“试聊/正式使用”制造额外会话心智
- [ ] 不因飞书未授权阻止所有普通对话
- [ ] 专家身份与受限能力说明不过度占用聊天空间
