# Proposal: industry-tone-examples

## Why

「今日优先级」在飞书无日程/待办时，模型常给出销售向占位示例（合同、复盘 PPT），与用户真实行业脱节。现有「关于我」自由文本不足以稳定驱动示例与口吻；产品又曾用硬规则禁止举例，导致要么乱编、要么追问过干。

需要结构化行业选择，让缺事实时的默认反馈口吻与占位示例可预期。

## Target Users

- 希望 KnowMe 用本行业说法协作的办公用户（研发、游戏、销售、教育、内容等）
- 飞书日程/待办时常为空、需要快速补一个真实目标再拆 Top3 的用户

## What

- 设置 → 我的记忆：增加行业单选（默认通用办公）
- 行业写入 settings，并注入轻量个性化上下文与系统提示口吻
- 今日优先级空态：用确定性行业 catalog 给出最多 3 条占位示例（标明非真实任务）
- 有飞书事实时行为不变

## Non-goals

- 不按行业切换工具 allowlist / 连接器授权
- 不自动切换助手模式
- 不改写写作入口任务卡片（catalog 可复用，本 Story 不做）
- 不猜测未选行业的垂直细节

## Success

- 选「游戏」后，飞书空态示例外观为游戏向，而非销售合同向
- 选「通用办公」时示例中性
- 「关于我」仍可补充细节，行业字段不替代它
- `npm test` / `npm run lint` 全绿
