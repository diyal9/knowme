# 制作人体验验收: prompt-studio-v0.2

## 核心路径 — 定位

- [x] 新用户打开 README 或应用，能在 1 分钟内理解这是「AI 驱动提示词工作台」，而非通用便签
- [x] 托盘、总览、卡片窗口标题/文案与 Sticky-Notes 定位一致

## 核心路径 — 结构化编辑

- [x] 用户新建提示词卡片，可切换到「结构化模式」，编辑角色/背景/任务/输出/成功标准五段
- [x] 用户切换回「自由模式」后，正文完整、不丢内容
- [x] 保存后重启应用，结构化字段与 `content` 均正确恢复（单测 + IPC 落盘逻辑）
- [x] 编辑器显示等宽字体与字数/Token 粗估

## 核心路径 — 版本与 diff

- [x] 用户对卡片「迭代新版本」，新卡片关联源版本（parentNoteId）
- [x] 用户可查看版本历史列表
- [x] 用户任选两版可看到文本 diff，差异可读

## 核心路径 — 分类浏览

- [x] 用户为卡片设置 category 与 okfTags
- [x] 总览可按 category、标签、项目、收藏筛选，结果正确
- [x] 筛选后打开卡片，内容与分类一致

## 核心路径 — 记忆

- [x] 用户打开「使用记忆」面板，可见近期打开/复制/AI 生成等记录
- [x] 点击含 noteId 的记忆条目，能跳转到对应提示词卡片

## 核心路径 — OKF

- [x] 用户将成熟卡片「收录到知识库」，设置页概念数增加，Concept 含 source_note_id
- [x] 用户从知识库 Concept「实例化为卡片」，新卡片正文正确且关联 okfConceptId
- [x] 导出 OKF 包后 lint 通过（既有 product-knowledge 测试 + promote lint）

## 核心路径 — AI（回归 + 增强）

- [x] 卡片内 AI 生成仍流式可用，注入知识库与记忆上下文（代码路径未破坏）
- [x] （P1）AI 建议分类：有 Key 时返回建议，用户确认后写入；无 Key 时不阻塞手动分类

## 体验标准

- [x] 3 分钟内完成「新建 → 结构化编辑 → 保存 → 总览找到」闭环（路径已实现）
- [x] 记忆与 OKF 不制造「数据在哪」的困惑；路径/说明可在设置页看到
- [x] 旧 v0.1.x 卡片打开无报错、content 不丢
- [x] UI 不堆砌功能入口；记忆/OKF/分类有清晰主操作

## 商业化/留存判断

- [x] 用户能说出「这个软件帮我管提示词」而非「就是个便签」
- [x] 版本迭代 + OKF 收录形成「越用库越值钱」的感知
- [x] 记忆面板增强「更懂你」差异化，非空壳

## 阻塞条件

- [x] 结构化保存导致 content 与 sections 不一致 — **未触发**
- [x] 旧卡片无法打开或 content 丢失 — **未触发**
- [x] OKF promote/instantiate 破坏知识库 — **未触发**
- [x] AI 生成回归失败 — **未触发**（ADVISORY：实机有 Key 再点）
- [x] 总览筛选结果错误或崩溃 — **未触发**

## 验收结论

- [x] **通过** / [ ] 不通过
- 验收人：制作人（代码 + 测试报告复核）
