# Proposal: knowledge-settings-refactor

## 一句话目标

精简设置「知识库」页：可查看概念正文、按主题勾选导出 OKF（全选=整包），文案更短更清。

## 目标用户

需要浏览本机知识、只分享某个分类（如仅「概念」）给同事的提示词用户。

## 为什么做

当前页路径条、双统计卡、多行记忆操作叠在一起偏乱；概念标签只能「实例化」不能预览；导出只能整包。

## 做什么

1. UI：精简说明；主题列表带勾选；点条目打开预览；导出/导入主操作保留，记忆入口收敛
2. 按勾选主题导出 OKF；未勾选时可用「全选」再导出（全选≈整包）
3. IPC：读概念内容；导出支持 `categories[]`

## 非目标

- 不在设置页内编辑/新建概念
- 不改 OKF 规范本身
- 不做云同步

## 验收标准

- 文案明显短于当前
- 可预览概念正文并可实例化为卡片
- 只勾选一个主题导出后，目标包仅含该主题概念且 lint 通过
- 全选导出概念数与整库一致
- `npm test` / `npm run lint` 通过
