## ADDED Requirements

### Requirement: 左栏过程块与对话同向贴底

管线执行间左侧对话区中的 Daemon 过程块 MUST 出现在空态引导或历史消息**之后**、输入区**之前**，MUST NOT 固定插在对话流顶部。过程日志行 MUST 保持时间正序（旧上新下）；当过程块可见且用户未主动离开底部时，MUST 便于看到最新日志行。

#### Scenario: 空态下过程块在引导下方

- **WHEN** 左栏显示「当前工作」空态且存在运行日志过程块
- **THEN** 垂直顺序为：当前工作引导 → 过程块 → 输入框

#### Scenario: 有消息时过程块在消息下方

- **WHEN** 左栏已有用户/助手消息且过程块可见
- **THEN** 过程块位于消息列表之后、输入框之前

#### Scenario: 日志刷新贴最新

- **WHEN** 运行日志因轮询增长且过程日志区可滚动
- **THEN** 日志区滚动位置靠近最新行（用户未明确上翻离开底部时）
