# Proposal: note-minimize-to-tray

## 一句话目标

便签顶栏「删除」改为「最小化到托盘」；任务栏/托盘恢复时优先回到刚才的编辑界面。

## 目标用户

编辑提示词时频繁切走桌面、又不想关窗丢上下文的用户。

## 为什么做

顶栏垃圾桶是高风险误触（永久删除）；用户更需要「先收起再回来」。多便签时任务栏恢复却打开总览，打断编辑心流。

## 做什么

1. 全文 / 分段两种编辑模式共用顶栏：原垃圾桶改为最小化图标，点击后隐藏全部窗口到托盘（内容不删）
2. 记录刚最小化时的便签 id；任务栏图标或托盘显示恢复时，优先 `showNote` 该编辑窗（而非多便签时直接弹总览）
3. 永久删除仍走总览/便签右键菜单确认；更新设置页相关文案

## 非目标

- 不改 ✕ 关闭（隐藏单窗 → 无其它窗时回总览）语义
- 不做 macOS Dock 专项改版
- 不把删除能力从产品中移除（菜单仍可删）

## 验收标准

- 编辑窗点最小化 → 窗口消失、进程托盘仍在；便签文件未删
- 再点任务栏图标 → 首先打开刚才那张编辑窗（全文/分段态保留）
- `npm test` / `npm run lint` 通过
