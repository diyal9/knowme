# QA Plan: polish-studio-canvas-node-summary-icons

## Smoke Scope（必填）

- [ ] 打开编排工作流专业画布：开始 / 专家 / 确认 / 结束节点图标与左侧组件库一致
- [ ] 多出入参或长标题节点：省略或「等 N 项」，无底边半截字；悬停标题可见全文
- [ ] 选中节点 → 右侧属性面板仍可编辑完整字段

## Regression Scope

- 拖拽、连线、删除/复制节点
- 轻量步骤列表模式不受影响
- 保存 / 测试运行入口仍可用

## Anti-pattern Checks（交给测试）

- 图标仍是 ▶■◆ 字符
- 卡片底部切断最后一行文字
- 摘要过短导致用户以为未配置（空态 warn 仍须可见）
