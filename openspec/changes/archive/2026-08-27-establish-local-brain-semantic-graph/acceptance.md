# Acceptance

## 结论

通过。Brain 已成为知识网默认首页，资料树作为可回退的二级视图保留；Memory、成长、伙伴 Profile 和外挂知识库的边界在界面与运行时保持一致。

## 体验验收

- 三栏首页可在“懂我 / 当前工作 / 知识版图”间切换；知识版图将确认后的本地认知按主题形成 Obsidian 式星图，双击主题后展开对应认知。
- 星图默认使用 42 节点密度，可切换 24 / 42 / 72 / 100；服务端保留 100 节点安全上限。
- 知识版图可切换“星图 / 归类”；归类模式使用 100 节点预算，以中心 Brain、外围领域社区和社区内资料三层结构呈现。
- Brain 全页面使用 KnowMe 共享的白色内容面、浅灰壳层与矿物青绿行动色；Obsidian 仅作为点线、缩放、聚焦和社区表达参考，不形成割裂的暗色子产品。
- 本地 LLM Wiki 的文档不计入 Brain 节点和主题，只显示“本地 LLM Wiki → Collection”的外围入口；库内文档只在资料视图或查询结果中按需出现。
- 确认关系、推断关系和外挂知识入口有不同视觉语言；布局为确定性二维投影，不持续抖动，并支持平移、缩放与空白处清除聚焦。
- 节点可拖动并持久化位置；“关系链”模式依次选择两个本地节点后，由 Brain 返回有证据的最短路径并高亮节点与关系。
- Inspector 能解释关系、证据、权威度和外部知识边界，并可修正/忘记本地理解。
- 搜索结果支持“仅本轮使用 / 收藏引用 / 沉淀到 Brain”，后者进入统一确认队列。
- 资料阅读器显示关联 Brain 节点、来源与可信程度，不再是孤立正文。
- 伙伴设置只保留学习权限、成长确认方式、敏感内容、项目保留与 Brain 读取范围，详细内容跳转 Brain。
- 伙伴设置显示统一 Growth Ledger；认知、协作方式与能力成长按目标分别提交，撤销后恢复对应 Brain、Profile 或 Capability 状态。
