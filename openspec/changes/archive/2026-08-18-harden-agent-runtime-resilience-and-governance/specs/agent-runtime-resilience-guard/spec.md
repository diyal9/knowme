## Purpose

为多 Builder 运行场景提供可预测的故障收敛能力，在远程链路不稳定时通过健康探针和自动降级保持任务可执行与可审计。

## ADDED Requirements

### Requirement: 远程执行必须有健康探针与降级策略

系统 MUST 持续评估远程后端健康度，并在探针指标超过阈值时按策略执行降级或阻断，不得静默重试至超时。

#### Scenario: 远程健康度恶化触发降级

- **WHEN** 远程握手成功率或超时率连续超过阈值
- **THEN** 系统按策略切换到本地执行并记录降级原因

#### Scenario: 降级不允许时触发阻断

- **WHEN** 当前策略禁用自动降级
- **THEN** 系统终止该次调度并返回可执行恢复建议

### Requirement: 降级行为必须可审计

系统 SHALL 为每次降级记录触发指标、时间、后端切换路径和结果摘要。

#### Scenario: 用户查询运行详情

- **WHEN** 用户查看含降级行为的 Run 详情
- **THEN** 系统展示降级触发原因与执行后端历史
