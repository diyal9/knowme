【结构化游戏需求案】



标题：七日登录奖励



完整性：可提交审批



### 背景

提升新用户 7 日留存，通过每日登录奖励建立习惯。



### 目标

7 日内每日登录可领取递增奖励；断签不清零累计天数展示。



### 玩法

主界面入口 + 奖励弹窗；每日 0 点刷新可领状态。



### 验收标准

连续登录 7 日奖励正确发放；断签后再次登录提示清晰；奖励幂等。
