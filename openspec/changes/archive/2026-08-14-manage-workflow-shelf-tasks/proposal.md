## Why

「工作流」Tab 下方「你的工作流任务」已可回看与打开，却缺少与任务 Tab「最近任务」对称的管理入口；用户无法就地批量勾选、按策略筛选并删除陈旧工作流任务，只能切回任务 Tab（且任务 Tab 已分流不含 `workflowId` 条目）。

## What Changes

- 「你的工作流任务」标题右侧增加设置图标（视觉与交互对齐「最近任务」管理入口）。
- 点击后打开「管理工作流任务」弹窗：列表、勾选、选择策略（全选 / 已完成 / 超过 1 个月 / 超过 3 个月 / 清空）、删除所选，界面与操作对齐现有「管理最近任务」。
- 弹窗仅列出带非空 `workflowId` 的任务；卡片副文案展示工作流名（非专家名），头像/图标用工作流语义回退。
- 删除仍走现有 `workbenchTaskArchive`；删除后刷新货架任务区与空态。

## Capabilities

### New Capabilities

- `workflow-shelf-task-manage`: 工作流货架「工作流任务」区的管理入口与批量删除弹窗。

### Modified Capabilities

- （无；货架任务列表既有行为不变，仅新增管理入口与弹窗）

## Impact

- `src/workspace.html`：货架最近任务标题旁增加设置按钮
- `src/workbench.js`：管理弹窗支持 expert / workflow 作用域
- `tests/workbench-templates.test.js`：结构断言
- 可选：`src/workbench-layout.css`（若需微调标题行对齐，优先复用现有样式）

## 目标用户

在「工作流」Tab 清理历史工作流运行记录的日常用户。

## 验收标准

1. 「你的工作流任务」标题右侧可见设置图标；点击打开管理弹窗。
2. 弹窗标题为「管理工作流任务」；列表仅含带 `workflowId` 的任务。
3. 底栏策略与「管理最近任务」一致；删除所选后列表与货架区同步更新。
4. 任务 Tab「管理最近任务」仍只管理专家任务，行为不回归。

## 非目标（Non-goals）

- 不在每张工作流任务卡片上单独挂设置菜单
- 不改归档 API / 任务 schema
- 不在弹窗内打开对话或改任务状态
- 不与「管理工作流」（货架包管理）合并为同一入口
