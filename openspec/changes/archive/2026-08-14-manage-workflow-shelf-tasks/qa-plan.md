# QA Plan: manage-workflow-shelf-tasks

## Smoke Scope（必填）
- [ ] 工作流 Tab →「你的工作流任务」右侧设置图标可见
- [ ] 点击设置 →「管理工作流任务」弹窗；仅列出工作流任务
- [ ] 勾选 + 删除所选 → 货架任务区同步消失
- [ ] 任务 Tab「管理最近任务」仍只含专家任务，策略/删除正常

## Regression Scope
- 工作流任务卡片点击打开任务
- 货架「管理工作流」包入口未受影响
- 空态：无工作流任务时管理弹窗空态正确

## Anti-pattern Checks（交给测试）
