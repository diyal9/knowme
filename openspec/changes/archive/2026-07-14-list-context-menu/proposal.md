# Proposal: list-context-menu

## Why

总览列表卡片目前只能左键打开 / 点星收藏，缺少右键快捷操作；便签窗口的完整右键菜单（复制全文、迭代、收录 OKF、关闭窗口等）与列表场景不对齐。

## What

为总览列表行增加**精简右键菜单**，仅包含与列表界面已有能力对应的项：

| 菜单 | 对应列表能力 |
|------|----------------|
| 打开 | 左键打开便签 |
| 收藏 / 取消收藏 | 行内星标 |
| 查看全部 N 个版本 | 「N 版」徽章（仅折叠且多版本时） |
| 删除… | 列表侧管理（确认后删除当前便签） |

不包含：复制全文、迭代新版本、复制卡片、收录知识库、关闭窗口。

## Out of scope

- 侧栏主题/项目项的右键
- 批量删除同项目全部版本
