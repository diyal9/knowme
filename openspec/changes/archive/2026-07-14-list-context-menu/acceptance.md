# 制作人体验验收: list-context-menu

## 核心路径

- [x] 总览列表卡片行可右键打开功能菜单
- [x] 菜单仅含与列表对应能力：打开、收藏、（条件）查看全部版本、删除
- [x] 无便签窗口专用项（复制全文 / 迭代 / 复制卡片 / 收录 OKF / 关闭窗口）
- [x] 「打开」与左键一致：打开便签并收起总览
- [x] 「收藏」与星标一致：列表刷新收藏态
- [x] 多版本折叠行：「查看全部 N 个版本」展开筛选，同「N 版」徽章
- [x] 「删除…」二次确认；取消保留；确认后该条消失且列表刷新

## 体验标准

- [x] 右键菜单可发现、项少不认知过载
- [x] 删除默认偏向安全（默认/取消 = 取消）
- [x] 不抢便签窗口完整菜单的职责边界

## 商业化/留存判断

- [x] 列表侧快速打开/收藏/删无效版本，降低「只能点进卡片再操作」的摩擦

- [x] 删除无确认 — **未触发**（双按钮确认框）
