# QA Plan: list-context-menu

## Smoke Scope（必填）

- [x] 列表卡片行右键弹出菜单（非系统默认菜单）
- [x] 菜单含：打开、收藏/取消收藏、删除…
- [x] 菜单不含：复制全文、迭代新版本、复制卡片、收录知识库、关闭窗口
- [x] 折叠且多版本时出现「查看全部 N 个版本」，行为同「N 版」徽章
- [x] 删除确认后列表刷新；取消不删
- [x] 左键打开 / 星标收藏仍可用（回归）

## Regression Scope

- [x] 便签窗口右键菜单（完整项）不受影响
- [x] 侧栏主题筛选、搜索、新建仍可用

## Anti-pattern Checks（交给测试）

- 右键空白区 / 侧栏是否误弹列表菜单
- 删除确认默认焦点是否在「取消」
- 折叠行删除是否只删最新一版（预期：是，非批量）
- 快速连点右键是否叠多个菜单/对话框
