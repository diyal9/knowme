## Why

长对话里用户常上滑阅读历史；当前 `renderChat` 只在「接近底部」时跟随，导致**用户主动发送新消息后仍停在旧位置**，看不到刚发出的气泡与思考态。需要明确「用户手势优先」与「发送强制到底」的优先级。

## What Changes

- 用户每次发送新消息（含快捷任务 / 建议条 send）后，对话区 MUST 滚到最新位置
- 流式增长与中间态重绘：若用户已上滑离开底部，MUST NOT 抢滚动焦点
- 用户滚回接近底部后，恢复自动跟随
- 补充 `agent-chat-ux` 行为契约（发送强制 vs 阅读优先）

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `agent-chat-ux`：明确发送强制滚底与用户滑动优先的优先级规则

## Impact

- 代码：`src/workspace-agent.js` 对话滚动跟随逻辑
- 体验：长列表候选 / 长回复场景下发送后立即看到最新气泡
- 无 IPC / 存储 / 依赖变更

## 目标用户

在工作台 Agent 中进行多轮长对话、需要边读历史边继续提问的办公用户。

## 验收标准

1. 无论当前滚动位置在哪，点击发送或 Enter 发送后，视口落在最新用户气泡 / 思考态附近
2. 生成过程中用户上滑阅读时，流式更新不把视口拽回底部
3. 用户自行滚回接近底部后，后续流式更新继续跟随
4. `npm test` / `npm run lint` 通过

## 非目标（Non-goals）

- 不改主题目录锚点跳转交互本身（仍可平滑跳到历史主题）
- 不引入「回到底部」浮动按钮（本轮不做）
- 不改便签页 / 编辑器旁聊的滚动逻辑
