# Code Review: redesign-goal-driven-workbench

## Scope

- `src/workspace.html`：目标首页、用户语言导航、响应式样式和高级模式入口。
- `src/workbench.js`：目标匹配、任务恢复、工作流启动上下文和模式推荐排序。
- `tests/workbench-templates.test.js`：页面契约与行为字符串回归。

## Review Notes

- 未新增 IPC、依赖或持久化字段，执行边界仍由既有工作流启动协议负责。
- `activeWorkflows()` 不再按模式硬过滤，只使用当前模式做排序，避免首页和模板页出现模式导致的空白。
- 无匹配目标时不会创建虚假任务；目标保留在模板页提示中，用户选择模板后会填入既有启动目标字段。
- 旧模式选择器仍保留在“高级”折叠入口，已有模式状态和绑定数据不迁移。
- 目标输入、起点卡片和任务卡均使用原生按钮/表单语义，并补充窄窗口回归。

## Findings

- 无阻塞问题。
- 后续可选增强：接入服务端意图推荐后，替换当前确定性关键词匹配，不改变本期页面契约。
