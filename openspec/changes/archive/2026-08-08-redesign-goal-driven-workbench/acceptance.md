# 制作人体验验收: redesign-goal-driven-workbench

## 核心路径

- [ ] 工作台 → 开始 → 输入“整理会议纪要并生成待办” → 开始。
- [ ] 开始 → 点击“制作宣传图” → 修改目标 → 查看启动预览。
- [ ] 开始 → 浏览全部模板 → 搜索并打开一个高级模板。
- [ ] 任务 → 查看失败任务 → 打开详情。
- [ ] 团队 → 查看和管理 Agent；重启后状态保持。

## 体验标准

- 用户不需要先理解工作模式、Agent 或工作流。
- 首屏 30 秒内可以开始一个真实任务。
- 无匹配目标时给出下一步，不出现死路。
- 专业能力仍可发现，普通入口不被专业术语打断。
- 默认和窄窗口布局稳定，焦点和按钮反馈清楚。
