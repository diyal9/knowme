## ADDED Requirements

### Requirement: 结束态产物区无外层卡片 chrome

管线/工作流运行结束态产物区 MUST NOT 使用独立的圆角白卡片外框（边框、阴影、实心底）。内容 MUST 直接落在运行区表面上，并在垂直方向铺满可用高度；产物/摘要区 MUST 可滚动；底栏动作区 MUST 贴底。

#### Scenario: 结果区扁平铺满

- **WHEN** 用户进入结束态结果页
- **THEN** 产物标题与列表不包裹在圆角卡片阴影容器中
- **AND** 内容区可滚动，底栏动作仍贴底可见

### Requirement: 结束态底栏无返回工作流

结束态底部动作区 MUST NOT 提供「返回工作流」；离开运行面 MUST 走顶栏返回。底栏 MUST 保留「再跑一次」「查看执行过程」，同一行横排，且每个按钮 MUST 同时展示图标与文字。

### Requirement: 结束态产物点击失败提示

用户在结束态点击产物条目时，若产物无法打开（尚未生成、未同步或接口不可用），系统 MUST 以错误 toast 提示「该产物尚未生成或未同步」。

### Requirement: 结束态查看执行过程打开过程日志

结束态底栏「查看执行过程」MUST 回到运行审阅面，并 MUST 聚焦「过程日志」Tab，展示 PROGRESS.MD 摘要与运行日志（与 Daemon WebUI 的进度/过程查看能力对齐）。

#### Scenario: 从结果页进入过程日志

- **WHEN** 用户在结束态点击「查看执行过程」
- **THEN** 切换到运行审阅面
- **AND** 激活「过程日志」Tab，可见 PROGRESS.MD 与运行日志区块
