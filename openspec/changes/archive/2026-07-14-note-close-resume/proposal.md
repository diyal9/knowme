# Proposal: note-close-resume

## 一句话目标

关掉便签后更快回到编辑：自动回到总览并高亮刚关的那条；托盘提供「继续编辑」。

## 目标用户

编辑提示词时频繁关窗再开的用户（置顶便签、skipTaskbar 导致任务栏找不到）。

## 为什么做

右上角 ✕ 只隐藏窗口，再编辑须手动开总览再点行，路径长、易丢上下文。

## 做什么

1. 关闭（隐藏）有内容便签、且桌面再无其它可见便签时 → 自动打开总览，并高亮刚关条目
2. 托盘菜单增加「继续编辑：{名称}」（记录最近一次有意关闭的 id）
3. ✕ 文案明确「隐藏并回总览（无其它便签时）」

## 非目标

- 不做系统任务栏最小化改版
- 不改删除逻辑；空便签关闭仍直接丢弃
- 「隐藏全部」、退出应用不弹总览

## 验收标准

- 只剩一张便签时点 ✕ → 总览出现且该行高亮，一点即可继续编辑
- 多张便签同时打开时关一张 → 不抢焦点弹总览；托盘仍有「继续编辑」
- `npm test` / `npm run lint` 通过
