## Why

工作台顶栏「进行中」按钮与下方「任务」首页 / 管线服务记录里的运行中列表职责重叠，多一处入口只会增加扫视成本，且 popover 里的卡片几乎是同一批运行的缩略版。用户已明确可删。

目标用户：在工作台查看与恢复运行中任务的日常用户。

商业化与体验价值：顶栏更干净，任务管理成为唯一心智入口，减少「到底看上面还是下面」的犹豫。

## What Changes

- **移除**工作台顶栏「进行中」按钮（`#wbRunningToggle`）及其 popover（`#wbRunningPopover`）整套 UI。
- **移除**与之绑定的显隐、点击、外侧点击关闭与列表渲染接线；运行恢复改走「任务」列表与「管线服务」记录筛选。
- 更新相关契约测试与引导文案，不再承诺「货架顶部进行中入口」。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `workspace`：工作台顶栏不得再提供「进行中」全局 popover；运行中任务由任务面 / 管线服务面承载。

## 验收标准

- 顶栏不再出现「进行中」按钮与数量徽标。
- 任务首页仍可看到并打开运行中 / 最近任务。
- 管线服务记录仍可用「进行」等筛选查看运行中项。
- 工作流运行中返回货架不中断运行；恢复入口不依赖已删除的顶栏按钮。
- 相关静态契约测试通过。

## 非目标（Non-goals）

- 不改 Run / Daemon 协议、状态机或持久化。
- 不重做任务首页或管线服务双栏布局。
- 不在货架卡片上新增第二种「进行中」条（本轮只删冗余顶栏入口）。

## Impact

- `src/workspace.html`：删除 toggle / popover 结构
- `src/workbench.js`：删除显隐与列表接线
- `src/workbench-shelf.css`：清理无用样式（可选）
- `tests/workbench-templates.test.js`：契约改为断言入口已移除
