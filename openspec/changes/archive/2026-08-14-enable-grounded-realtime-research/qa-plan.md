# QA Plan: enable-grounded-realtime-research

## Smoke Scope（必填）

- [x] 输入“帮我看下今天关于 AI 的资讯”，直接进入“搜索网络 → 读取网页 → 核验依据”，不出现单项飞书来源选择
- [x] 最终回答展示可追溯 URL，并区分发布时间与检索时间
- [x] 搜索 provider 失败时返回真实原因，不输出虚构的今日资讯
- [x] 普通问候仍走轻量对话，已知 URL 仍使用网页读取，飞书链接仍走飞书工具

## Regression Scope

- [x] Tool Registry v1/legacy 模式行为与契约覆盖
- [x] Agent v2 输出、时间线、结构化选择与滚动稳定性
- [x] 本地知识库、飞书连接器与 MCP allowlist 投影
- [x] 网页抓取 SSRF、重定向、超时和体积边界

## Anti-pattern Checks（交给测试）

- [x] 能执行时仍让用户选择内部工具
- [x] 只有一个选项却显示“选择一项”
- [x] 把飞书知识库当作公共最新资讯的默认来源
- [x] 未调用搜索却声称“正在检索”或“已检索”
- [x] 把搜索摘要冒充原文，或把检索时间冒充发布时间
- [x] 来源重复、失效、私网 URL 或无链接事实进入答案
- [x] provider/页面失败后编造内容或隐藏错误
