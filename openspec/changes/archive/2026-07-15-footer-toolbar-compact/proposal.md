# Proposal: footer-toolbar-compact

## 一句话目标

便签编辑窗底栏去拥挤、统一视觉：左侧仅保留文本/MD 模式切换，预览并入中间紧凑工具组，右侧 AI 助写与复制样式对齐。

## 目标用户

在窄窗编辑 Markdown 便签、频繁切换预览与收藏/入库操作的用户。

## 为什么做

当前底栏：三段式 mode-seg（文本/MD/预览）+ 独立描边星标 + 幽灵图标 + 两个加框文字按钮，视觉权重不一、横向过满。

## 做什么

1. `mode-seg` 只留「文本」「MD」两钮，保持现有分段样式
2. 「MD 预览」移入中间工具组，与收藏/入库/智能分类/历史统一为紧凑图标钮
3. 「AI 助写」「复制」改为统一的轻量 action 样式（同高、同圆角、同描边权重）

## 非目标

- 不改预览/收藏/AI/复制业务逻辑与 IPC
- 不改顶栏、侧栏 AI 面板内部布局

## 验收标准

- 左侧分段仅两钮；预览在中间工具组，MD 模式下可点、纯文本禁用
- 中间图标间距紧凑、高度一致
- AI 助写与复制视觉统一，悬停/复制成功反馈仍可用
- `npm test` / `npm run lint` 通过
