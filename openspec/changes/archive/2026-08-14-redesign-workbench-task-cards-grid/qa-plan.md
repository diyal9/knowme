# QA Plan — redesign-workbench-task-cards-grid

## Smoke Scope

- 任务首页「你的任务」三列卡片布局（宽屏）
- 卡片展示执行摘要（结果 / 目标 / 状态回退）
- 收起预览高度：常见窗口下任务首页无需页面滚动
- 「更多 / 收起」与列表内滚动
- 点击卡片打开任务；卡片内「定时」可用
- 空态文案

## Cases

| # | 步骤 | 期望 |
|---|------|------|
| 1 | 宽屏打开任务 Tab，快捷专家 ≥4 | 默认仅一排 3 卡；显示「更多」 |
| 2 | 点快捷专家「更多」再「收起」 | 展开可操作全部；收起回一排 |
| 3 | 宽屏打开任务 Tab，有 ≥3 条任务 | 预览呈三列卡片，含摘要 |
| 4 | 任务 > 预览条数 | 默认收起；首屏可见快捷 + 最近预览，无需页面滚动 |
| 5 | 点任务「更多」再「收起」 | 展开可列表内滚动；收起回到预览 |
| 6 | 点卡片 / 定时 | 打开任务 / 打开定时弹层 |
| 7 | 无任务 / 无快捷专家 | 空态，无「更多」 |

## Out of scope

- 任务持久化迁移、分页 API、快捷任务区改版
