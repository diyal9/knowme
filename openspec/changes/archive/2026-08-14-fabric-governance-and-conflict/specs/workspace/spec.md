## MODIFIED Requirements

### Requirement: Knowledge center governance tab

WHEN user opens knowledge center  
THEN a primary tab labeled「治理」SHALL be available.

WHEN user clicks「运行体检」  
THEN UI SHALL display health scores, issue categories, and per-issue action buttons using async button hardening.

WHEN no issues exist  
THEN empty state SHALL offer「运行体检」or「连接资料」actions.
