# agent-workbench (delta)

## ADDED Requirements

### Requirement: 交付路径下拉选项须有淡色分割线

管线服务创建任务表单中的「交付路径」选择器 MUST 在展开列表中以轻微淡色水平分割线区分相邻选项，以便长中文路径名扫读。选择器 MUST 保持与原先一致的选择语义（选中路径后刷新开工上下文）。MUST NOT 依赖无法样式化的系统原生 option 弹出层作为唯一呈现。

#### Scenario: 展开可见淡色分割线

- **WHEN** 用户打开管线服务并展开「交付路径」列表且存在不少于两条可选路径
- **THEN** 相邻选项之间呈现淡色水平分割线
- **AND** 分割线不明显压过正文（轻微、低对比）

#### Scenario: 选择路径行为不变

- **WHEN** 用户从交付路径列表中选中另一条可用路径
- **THEN** 触发器显示新路径名称
- **AND** 系统按原逻辑刷新该路径的开工上下文并更新操作台
