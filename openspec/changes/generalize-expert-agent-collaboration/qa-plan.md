- [x] 22 个内置专家的全部声明交付物，以及缺少有效 AI 配置的异常路径。

## Acceptance focus

- 不出现具体专家 ID 驱动的平台分支。
- 不出现文字假装工具成功、空图片卡片或状态与成果矛盾。
- 任务编号、状态、对话、预览、验收和修改链路连续且可调试。
- 专业质量属于 Agent 包；平台必须完整传递上下文、工具、证据和成果，不截断专家最终答复。
