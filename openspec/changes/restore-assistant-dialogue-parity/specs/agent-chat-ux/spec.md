## ADDED Requirements

### Requirement: 快捷操作与模型选择分离

助理输入条 MUST 同时提供独立的快捷操作按钮（Ctrl+K）与模型选择按钮。模型按钮 MUST NOT 承载快捷操作图标。工作台对话 composer MUST NOT 挂载 Ctrl+K 快捷菜单。

#### Scenario: 空态首屏两个按钮并列

- **WHEN** 用户打开无用户消息的助理空态
- **THEN** 可见「快捷操作」按钮与「选择模型」按钮，且模型按钮文案不含快捷操作图标混排

#### Scenario: 对话中仍可打开快捷菜单

- **WHEN** 已有用户消息且用户按下 Ctrl+K 或点击快捷操作
- **THEN** 打开快捷任务菜单，且菜单不位于模型选择按钮内部

### Requirement: 助理执行过程使用消息时间线

助理在生成过程中 MUST 将 stage/tool 事件投影为当前助手消息的执行时间线。助理列 MUST NOT 渲染工作台 Daemon「过程 / 运行日志 / 返回工作台」卡片。

#### Scenario: 上下文准备完成出现在执行进度中

- **WHEN** 流式事件发出 `stage` 且标题为「上下文准备完成」
- **THEN** 当前助手气泡显示执行进度条目（友好文案「内容整理完成」），且页面没有「返回工作台」过程卡
