# Agent 范围内的能力聚合与上下文优化

## 目标用户

使用伙伴、专家协作和工作流完成知识工作的 KnowMe 用户。Agent 定义职责和默认能力范围，任务决定本轮加载内容，主进程负责权限、预算、执行证据与恢复。

## 验收标准

- 未授权副作用不得执行，HTTP 连接器凭据不得被转发至未授权源。
- 完整能力目录可发现，本轮只投影相关定义；Skill 激活包含依赖和验收契约。
- 消息与工具 schema 共同受预算约束，关键规则和当前用户输入不能静默截断。
- 明确区分能力授权、身份认证、操作批准、用户补充和成果验收。
- 旧任务恢复不伪造用户消息/执行证据，不丢已确认目标或队列附件。
- 完成专项离线回归、全量 check、lib 类型检查和独立 review；真实供应商验证单独记录，未执行不能记为通过。

## Non-goals

不另建 Context Engine，不增加固定独立规划模型，不引入新图数据库，不默认启用远程语义服务，不自动扩大永久权限，不重做无关界面。

## 关联变更

在 establish-context-engine、build-managed-connector-tool-platform、generalize-expert-agent-collaboration 的现有实现上增量改进；不覆盖其历史验收记录。
