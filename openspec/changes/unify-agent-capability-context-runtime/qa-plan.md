# QA 计划

## 离线硬性不变量

1. WHEN 操作尚未批准或批准参数不匹配 THEN handler 不执行。
2. WHEN HTTP URL/重定向跨源 THEN 拒绝且不向第二源发送凭据。
3. WHEN 动态 Skill 的有效契约未满足 THEN 不发出成功终态。
4. WHEN 能力超过 64/500 项 THEN 仍可分页发现尾部相关工具，不全量注入 schema。
5. WHEN Skill 禁止模型自动调用、资源过长或依赖缺失 THEN 明确返回可处理状态，不静默使用不完整规则。
6. WHEN 工具 schema 加入请求 THEN 仍满足输入预算，当前用户输入和关键规则完整。
7. WHEN 用户未选择/授权/验收 THEN 保持等待，不自动调用下一项。
8. WHEN 重启或补充文字+图片 THEN 保留确认目标和附件关联，不重放未知结果写操作。

## 测试层次

纯模块单测 → 严格模拟工具执行器集成 → Renderer 状态/交互回归 → check 与 lib 类型检查 → 独立代码 review → 真实连接器 canary。

模拟模型必须通过提供的发现/加载工具获得定义，不能由测试暗中补齐。禁止读取生产凭据并写入日志/fixtures。真实测试没有资源授权时记录未执行，不替换为模拟通过。

## 对照指标

相同任务集合记录完成率、选择准确性、schema token、消息 token、选择延迟和重试次数。500 项目录用于评估增长行为；不将不同任务的 token 差异视为优化收益。

## Smoke Scope

- [x] 未授权副作用、跨源凭据、撤销后调用、父子范围隔离。
- [x] 超过 64/500 项目录分页、完整 Skill 激活与资源续读、schema 联合预算。
- [x] 普通审批入口、精确 checkpoint、连续审批回执与冷恢复防重放。
- [x] 原生 Brain 项目隔离、知识源缓存身份、旧记忆归属和引用去重。
- [x] 未选中 MCP 冷连接器零连接，按需激活后的下一轮动态 schema。
- [x] 最后稳定补丁后的完整 check/gate。
- [ ] 配置测试模型与授权资源后的真实供应商及桌面人工体验验收。
