# 专项验收边界

## 产品约定

知识来源是 KnowMe 原生 Brain / LLM Wiki / RAG；外部源允许后续配置选择，不以飞书 Wiki 为默认或必需知识库。Agent 默认范围、任务临时授权、连接器认证和一次操作批准分别管理，不自动扩大永久权限。

## 工程验收

以 test-report.md 中最后稳定补丁后的完整检查为依据，不以中途某次绿灯代替最终复验。严格模拟模型经公开发现入口选择冷连接器，下一轮获得实际定义；原生 Brain 使用本地临时数据，其余协议测试明确标注替身。

冻结源码后 `npm run check`、`npm run typecheck:lib` 和专项 harness gate 全部通过：后端 3219 通过、51 跳过、0 失败；Renderer 597 通过。工程回归达到本轮门禁，不代表下列真实体验与发布验收已经完成。

审批前置、跨域凭据保护、撤销即时生效、必要契约预算保护、待用户动作不推进和不确定写入不重放均有专项回归。成果仅在接受后进入最终区域，文字与附件原子排队，恢复不制造用户消息。
