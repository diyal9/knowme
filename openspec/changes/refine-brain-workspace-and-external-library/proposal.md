# Why

Brain 已经正确区分本地认知与外挂知识库，但空 Brain 缺少可理解的组织骨架，三栏常驻布局压缩了图谱空间，“来源”页也仍像普通说明页，无法承担外部知识库管理职责。

# What Changes

- 根据用户当前行业与岗位初始化版本化的 Brain 分类骨架，岗位变化时幂等替换骨架并保留真实认知。
- 分类骨架只负责组织，不计入“已理解”，不进入稳定个性化或本地检索结果。
- Brain 首页默认收起筛选和详情栏，以紧凑控制条按需展开，扩大中央图谱。
- 将“来源”重做为外部知识库管理台，分离选择、默认源、连接、目录同步、Collection 授权与断开操作。
- 将一级信息架构收敛为 `Brain / 知识库 / RAG`，待确认作为 Brain 工具栏中的受控工作流继续保留。
- Brain 默认使用岗位分类循环图：本地 Brain 位于中心，岗位主题形成外围循环，主题内认知按需钻取；外部知识库不进入该图。
- 本地知识库页支持选择目录并配置多个 LLM Wiki Provider，提供目录树、预览、默认库与移除操作。
- RAG 页独立管理多个 RAGFlow 连接、加密密钥、Dataset 授权和检索目录。
- 继续保证外挂 LLM Wiki、RAGFlow 与其他 Provider 正文不属于 Local Brain。

# Acceptance Criteria

- 新用户按当前岗位得到 8 个稳定分类入口，且理解统计不因此增加。
- 岗位变化后旧分类骨架被替换，用户已确认的节点不丢失。
- 分类节点不参与 Brain Query 命中，但实际认知可按分类标签或关键词归类。
- 1280×800 下筛选和详情默认收起，中央画布占据主要空间，并可键盘展开。
- 来源页可独立管理 Provider、默认检索源、Collection 授权、目录刷新、编辑连接和断开。
- 1280×800 下 Brain 只保留 52px 图标工具栏，分类循环图占据主要内容区。
- 本地知识库与 RAGFlow 分属两个独立页面；本地页可挂载至少两个 LLM Wiki 目录并分别浏览目录。
- RAGFlow 使用官方 `/api/v1/datasets` 与 `/api/v1/retrieval` 协议，API Key 仅经 Electron safeStorage 加密落盘。
- 本地 LLM Wiki 明确显示为外挂来源，不进入本地认知统计。

# Non-goals

- 不把岗位模板当作用户事实或能力证明。
- 不复制外部知识库正文、切片或向量。
- 不引入新的数据库或图谱渲染依赖。
