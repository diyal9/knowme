## 变更摘要

管线服务首页重构为双栏：

- **左**：创建新任务（目标 ≥20 字或附件、交付路径、补充材料、开始开发）
- **右**：管线任务列表（搜索、图标状态筛选、卡片点进运行）

## 手动路径

1. 工作台 → 管线服务：左表单 + 右列表，无路径三栏。
2. 未满 20 字且无附件时「开始开发」禁用并见红字提示。
3. 填写足够描述或上传附件后可提交（在线且有可用路径）。
4. 右侧搜索/筛选过滤列表；点击卡片进入既有 Daemon 任务运行页。
