# Code Review

通过目标范围审查。

- 导入复用 Capability Hub 的预览 token、内容哈希和注册生命周期，没有新增旁路写入协议。
- 工作流 ID 冲突处理确定性且同仓库重导幂等；来源路径、仓库 ID 与内容哈希保留在 provenance。
- 缺少工作流存储或引用未导入专家时逐项失败并如实报告，不生成伪可执行工作流。
- 专家写工具声明为 medium-risk、需要批准；只读预览与写入提交分离。
- 未发现将 `th-art` 连接器凭据写入仓库、日志或用户可见预览的路径。

已知限制：当前通用适配契约是 Cursor 风格兼容层；其它项目需先生成最小 `.cursor` 描述层，业务代码保持链接到原项目。
